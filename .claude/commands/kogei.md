# KOGEI の記事ルール

基本は `.claude/commands/research.md` の「鉄則（信頼性）」と文章の質チェック（PREP法・h2直下の結論・具体例）に従う。テンプレートは `.claude/commands/kogei-template.html`。以下は KOGEI 固有の上書きルール。

## 立ち位置・トーン（research.md と違う点）

**レポート・ジャーナリズム調。** 読者は「悩み」を抱えているのではなく、工芸品やニュース、旅行、ギフト探しの延長で「この工芸品って何がすごいの」と検索してくる。Before→After の悩み解決型には寄せない。

- 断定的で事実ベース。一人称の感想（「筆者は〜と思う」）や煽り表現を書かない。
- 「AIが調べた」という語りは記事本文に出さない。AIによる作成である旨は `/about/` ページのみで淡々と開示する（`about` フィールドの通り）。
- 特定の工房・ブランド・商品を宣伝する書き方（「おすすめ」「買うべき」等）をしない。技術・歴史・産地の構造的な課題を報告する立場を保つ。
- 導入は「へえ」と思わせる意外な事実・数字から入る（例: 工程数、職人数の推移、産地の最盛期と現在の比較）。

## 読者

日本の伝統工芸に興味はあるが専門知識はない一般の人。10分で「この工芸の技術・歴史・今の課題」を理解できることがゴール。

- 専門用語（蒔絵、練り込み、経糸・緯糸 等）は初出で必ず平易に言い換える。
- 「〜と言われている」で逃げず、産地組合・自治体・研究機関・報道機関の一次資料が何を報告しているかを明確に書く。
- 職人・産地を美化しすぎない。後継者不足・売上減少などの構造的課題も具体的な数字とともに書く。

## 出典

産地組合・伝統的工芸品産業振興協会（伝産協会）・自治体（経済産業省の伝統的工芸品指定資料等）・大学や研究機関の調査、全国紙・専門紙の報道に限る。個人ブログ・まとめサイト・EC販売ページの宣伝文だけを根拠にしない。数値（職人数、生産額、創業年等）は必ず一次資料か報道で確認する。

## 記事の種類ごとの構成（設定の types は guide のみ）

テンプレートの見出し: 01 この工芸は何か（技術の正体）/ 02 産地とその歴史 / 03 技術を、生活の言葉で / 04 後継者問題とテクノロジーとの交差点 / 05 関連する工芸 / 06 よくある質問 / 出典。「この工芸から考えた、こんなアプリ」（APP IDEA）は2026-09-23〜廃止（research.md参照）。

- 04「後継者問題とテクノロジーとの交差点」は KOGEI の核。3Dプリンタ・EC・デジタル記録・海外展開など、具体的な技術との接点を必ず一次資料ベースで書く。憶測で「〜すべきだ」と提言しない。
- 05「関連する工芸」は既存記事があれば `/{スラッグ}/` にリンクする。まだ無ければこのブロック自体を省略してよい（存在しないリンクを書かない）。

## 投稿データ（media.md 手順5）

`media/kogei-posts.json` の先頭に `{"slug","category"(設定のcategoriesのname),"type":"guide","date","title","summary"}` を追加する。

## 写真のルール（記事ごとに1枚。umbra/tetsugaku のカテゴリプール方式ではない）

- `python3 media/photo.py kogei {記事slug} "<英語の検索語 2〜4語>"` を1回実行する。検索語は工芸品そのもの・道具・産地の風景に寄せる（例: "lacquerware bowl craft", "kiln ceramics workshop"）。人物の顔が写る写真は避ける。
- 候補なし・失敗時は写真なしで続行する（リトライ・複数回検索は禁止）。
