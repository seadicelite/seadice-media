# 犯罪と心理 の記事ルール

基本は `.claude/commands/research.md` の「読者」「鉄則（信頼性）」「手順」に従う。テンプレートは `.claude/commands/hanzai-template.html`。以下は 犯罪と心理 固有の追加・上書きルール。

## 立ち位置（最重要）

**「身を守りたい人」ではなく「知りたい人」のためのメディア。** 人はなぜ罪を犯すのか、目撃証言はなぜ間違うのか、無実の人はなぜ自白するのか、といった犯罪をめぐる人の心の仕組みを、研究で読み解く。具体的な防犯対策（施錠・詐欺の見分け方など）は姉妹メディア「防犯」（bohan.seadice.win）の担当なので、ここでは書かない。題材が近い場合は、防犯は「対策」、犯罪と心理は「心の仕組み」と役割を分け、同じ結論の記事を作らない。

**記事の軸は「通説・素朴な疑問 → 研究でわかったこと → 思い込みとの違い」。** 有名な実験や通説（傍観者効果、服従実験、監獄実験など）は、その後の追試・再検証まで含めて紹介する。「研究で何がわかっていて、何がわかっていないか」を正直に書く。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 実在の事件・人物を興味本位で扱うこと。事件名を出してよいのは、査読論文で研究対象として検証されている歴史的な事例（例: 「38人の目撃者」の再検証）に限る。その場合も被害者の尊厳を守り、事件の残虐な描写はしない。私人の実名、最近の事件、係争中の事件は扱わない。
- 犯罪の具体的な実行方法として使える手順・手口の詳細。
- 犯罪者を美化・英雄視する表現、「サイコパスは頭がいい」等の俗説の無批判な紹介。
- 特定の地域・国籍・民族・障害・属性の人と犯罪を結びつける記述。
- 恐怖や好奇心を煽る表現（「戦慄の」「恐ろしい」「衝撃の」等）、断定（「絶対に」）。
- 診断・治療の助言。精神疾患と犯罪を短絡的に結びつける記述。
- 開発側の事情（課金・価格）、商品・サービスの紹介。絵文字。

## 出典

犯罪心理学・社会心理学・法と心理学・犯罪学の査読論文、メタ分析・システマティックレビュー、法務省（犯罪白書）・警察庁・裁判所などの公的統計、大学・公的研究機関に限る。業者の調査や報道だけを根拠にした記述は使わない。有名な実験は原典に加え、追試・再検証の論文も確認する。統計を使うときは何年の数値かを必ず書く。確認できなかった数値は書かない（research.md の鉄則どおり）。

## 記事の構成（設定の types は guide のみ）

テンプレートの見出しをそのまま使う。01 どんな心の仕組みが働いているのか / 02 研究でわかっていること / 03 よくある思い込みと、研究が示す実際 / 04 日常で生かせる視点 / 05 よくある質問 / SOURCES。
- 02の結論文の直後に `.stats`（核心の数字2〜4個）、続いて研究1件につき `.study` を1枚。
- 03は `.myth` カードを2〜3枚（MYTH＝よくある思い込み、FACT＝研究が示す実際）。
- 04は読者が日常（ニュースの見方、裁判員になったとき、人との関わり方など）で生かせる視点を箇条書きで3つ。防犯の手順にはしない。
- 関連アプリ欄・APP IDEA は入れない。

## 投稿データ（media.md 手順5）

`media/hanzai-posts.json` の先頭に `{"slug","category"(設定のcategoriesのname),"type":"guide","date","title","summary"}` を追加する。

## 写真のルール

`ledger.md` の写真のルールと同じ（`python3 media/photo.py hanzai {記事slug} "<検索語>"`、候補なしは検索語を変えて2〜3回まで再検索、使い回しは最終手段）。加えて、人の顔がはっきり写った写真、実在の事件現場・裁判の当事者の写真、広告や看板が目立つ写真は使わない。落ち着いた静かな写真（夜の街路、建物、物、風景）を選ぶ。
