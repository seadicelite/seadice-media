# チョコの研究 の記事ルール

基本は `.claude/commands/research.md` の「鉄則（信頼性）」と `docs/quality/base.md`・`article.md` に従う。テンプレートは `.claude/commands/choco-template.html`。以下はチョコの研究固有の追加・上書きルール。お煎餅ラボ（`senbei.md`）と同じ型で、題材だけが違う。

## 立ち位置（最重要）

**キャッチコピーは「科学で目指す究極のチョコ」。究極のチョコとは、①食べたあとにもう一度食べたくなる ②誰かにあげたくなる ③もう一度買いたくなる、の3つを満たすチョコ（2026-10-20、ユーザーが決めた定義）。目標であって実績ではない。**

**どの記事も、この3つのどれに効く話かを意識する。** 03「開発への使い方」や結論で、その研究が3つのどれに近づく手がかりかを一言添えてよい（無理につなげない。つながらないなら書かない）。**読者はチョコ製品を開発する人**（チョコレートメーカー・ショコラティエ・菓子メーカーの商品開発・品質管理。2026-10-21 ユーザー決定）。食べる人の悩み（ニキビ・賞味期限など）はこのメディアでは書かず、悩みの科学（research）に書く。

**中身をよくする方法を書き、錯覚で中身以上に見せる方法は勧めない。** 包装の重さ・値段・表示で味の感じ方が変わる研究は、「評価のときに外す条件」「買う人の期待と中身をずらさないための知識」として紹介し、「箱を重くして濃く感じさせる」のような手は勧めない。「バズる」のような煽る言葉は使わない。 「究極のチョコを作った」「最高のレシピ」のように、達成したと読める書き方をしない。

**1記事＝1つの問い＋主役の研究1本。** 問いはチョコ好き・作り手が実際に思う疑問（「チョコはなぜパキッと割れて口で溶ける？」）。主役の研究を1本決め、その研究を「誰が・何を・どう調べたか」まで説明する。補う研究は記事の中で紹介してよい（主役より目立たせない）。

**「研究で示された」まで。** 「科学的に証明」「必ず」「絶対」と書かない。カカオバターだけ・モデル系・市販品・他の油脂の研究を使うときは「カカオバターだけを使った研究では」のように対象を必ず書き、チョコ全体の結論として言い切らない。

**健康効果を盛らない。** カカオポリフェノール・フラバノールの研究は、多くが抽出物や高用量で、市販のチョコの量とは違う。「チョコで血圧が下がる」「ダイエットになる」と書かない。病気の予防・治療をうたわない。体と安全の記事は「言えること／言えないこと」を分ける。

**何も売らない。** 商品名・店名・ブランド名を勧めない。道具や材料も一般名で書く（「調理用の温度計」はよい、型番は書かない）。研究で使われた市販品は、製品名を出さずに「市販のダークチョコ5種類」と書く。広告・アフィリエイトなし。絵文字禁止。

**Before→After** は「配合や工程を経験と言い伝えで決めている開発者 → どこまで研究でわかっていて、次の試作で何を1つ変え、どう評価すれば確かめられるかがわかる開発者」。

## 出典の基準

- 使う: 査読論文（食品科学・油脂の結晶学・感覚科学・栄養学）、公的研究機関の報告、農林水産省・食品安全委員会・FDA・EFSA など公的機関の資料。
- 使わない: メーカーやショコラティエの宣伝・商品ページ、まとめサイト、料理サイトの言い伝え。
- 業界団体・メーカー出資の研究は、出資元を本文に書く（チョコの健康研究はメーカー出資が多い）。
- 下調べのメモがあっても、記事に書く数字は**自分で原典を開いて照合したものだけ**。書誌しか確かめられない文献は数字を書かない。
- 研究者の所属・試料・人数は原典のページで確かめて書く。

## 研究の確かさ（★3段階）

h1直下の `.evidence` に必ず付ける。
- ★★★: チョコ・カカオバターで複数の研究（査読あり）が同じ向き
- ★★☆: チョコの研究はあるが少ない、または条件が限られる（モデル系・少人数）
- ★☆☆: チョコの研究がほとんどなく、近い食品や油脂の研究からの推測。結果が分かれている

## 記事の構成（テンプレートの見出しの並びをそのまま使う）

結論（`.summary`、2〜3行） / 01 どんな研究か / 02 わかった数字 / 03 開発への使い方 / 04 まだわからないこと / 05 よくある質問 / 出典。

- 大きい見出しは読者の問いにする。
- 02 は `.stats` に核心の数字2〜4個（条件つき）。比べる軸が2つ以上あるときだけ表（`.tbl`）。
- 03 は開発で使えることを3つ。①配合・工程で決めること（どの条件を1つだけ変えて試作するか）②評価の組み方（官能評価のパネル・尺度・比べ方、機械測定なら何を測るか）③品質管理・表示で気をつけること、の形を基本にする。研究の条件（試料・人数・設備）と自社ラインの違いを1文添える。「必ず効く」と書かず「試作で確かめる価値がある条件」と書く。体と安全の記事は、表示・含有量の管理・注意書きの観点でよい。
- 04 は省略しない。「チョコで直接調べた研究は見つからなかった」を正直に書く。
- 本文は2,500〜4,000字（研究カード・表・FAQを含み、出典を除く）。
- 本文から同じメディアの記事へ2本以上リンク（`ls sites/choco/` で存在を確認）。04の下の `.labnav` で `/tool/` と `/research/` へつなぐ。
- 記事を足したら、`media/choco-pages.json` の研究一覧（`/research/`）で、その文献の行に記事リンクを足す。テンパリング温度ガイド（`/tool/`）の根拠に使える記事なら、ツールの根拠リンクも記事に差し替える。

## 投稿データ（media.md 手順5）

`media/choco-posts.json` の先頭に `{"slug","category"(豆と発酵|焙煎と練り|テンパリング|口どけと保存|香りと味|感じ方|体と安全),"type":"study","date","title","summary"}` を追加する。タイトルは「問い。研究の答え」の形（最初の「？」までで問いとして読めるようにする）。

## 写真のルール

`python3 media/photo.py choco {記事slug} "<英語の検索語>" --alt="<写っている物>"`。カカオの実・豆・割ったチョコ・溶かしたチョコ・温度計・大理石の台など、物の写真に寄せる。商品パッケージ・ロゴ・ブランド名が読める写真は使わない（売らない方針のため）。人の顔がはっきり写った写真は使わない。Commons の説明文に商品名・メーカー名があるものも使わない。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 「究極のチョコを作った」「最高のレシピ」など、目標を実績のように書くこと。
- 「科学的に証明」、出典にない「必ず」「すべて」。
- 商品名・店名・ブランドの推奨、購入リンク、アフィリエイト。
- 確かめていない数字、検索結果の抜粋だけを根拠にした数字。
- カカオバターだけ・抽出物・動物実験の研究を、対象を書かずにチョコの結論として書くこと。
- 健康効果の誇張（「痩せる」「血圧が下がる」「頭が良くなる」）、病気の予防・治療をうたう表現、重金属などで不安を煽る表現。
- 絵文字、開発側の事情（課金・価格）。

## 自己検査（media.md 手順6に加えて）

- 研究者の所属・試料・人数・条件が原典どおりか。
- 結論の向きが原典と同じか（「示唆される」を「示された」に強めていないか）。
- 交絡（ほかに違っている条件）・出資元があるとき、それを書いたか。
- タイトルと説明文（description）には、研究が実際に測ったもの（機械の測定か人の評価か、何の項目か）と、主な限定（カカオバターだけ・少人数など）を入れる。本文の但し書きだけで済ませない（検索結果とAIの引用はタイトルと説明文だけで読まれる）。
- テンパリング温度ガイド（`/tool/`）の温度・理由と、記事の結論が食い違っていないか。
