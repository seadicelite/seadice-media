# お煎餅ラボ の記事ルール

基本は `.claude/commands/research.md` の「鉄則（信頼性）」と `docs/quality/base.md`・`article.md` に従う。テンプレートは `.claude/commands/senbei-template.html`。以下はお煎餅ラボ固有の追加・上書きルール。

## 立ち位置（最重要）

**目標は「研究で、世界一美味しい煎餅を目指す」。これは目標であって実績ではない。** 「世界一の煎餅を作った」「最高の煎餅のレシピ」のように、達成したと読める書き方をしない。

**1記事＝1つの問い＋主役の研究1本。** 問いは煎餅好き・作り手が実際に思う疑問（「天日干しの煎餅はなぜふくれる？」）。主役の研究を1本決め、その研究を「誰が・何を・どう調べたか」まで説明する。補う研究は記事の中で紹介してよい（主役より目立たせない）。

**「研究で示された」まで。** 「科学的に証明」「必ず」「絶対」と書かない。煎餅そのものの研究は少ない。パン・スナック・タイの米菓・餅など、煎餅以外の研究を使うときは「玄米パフの研究では」のように対象を必ず書き、煎餅の結論として言い切らない。

**何も売らない。** 商品名・店名・ブランド名を勧めない。道具や材料も一般名で書く（「オーブン用温度計」はよい、型番は書かない）。研究で使われた市販品を説明するとき（「市販の柿の種5種類」）は、製品名を出さない。広告・アフィリエイトなし。絵文字禁止。

**Before→After** は「煎餅の美味しさを何となく好み・言い伝えで語っている自分 → どこまで研究でわかっていて、次の手作りで何を1つ変えて確かめればいいかわかる自分」。

## 出典の基準

- 使う: 査読論文（食品科学・農学・感覚科学）、県の工業技術センター・農業試験場など公的試験研究機関の報告書、農林水産省・食品安全委員会など公的機関の資料。
- 使わない: 米菓メーカーの広告・商品ページ、まとめサイト、料理サイトの言い伝え。
- **試験場の報告書は査読なし・試作の数が少ない**ことを本文に書く（「茨城県工業技術センターの試作（1条件5〜10枚）」のように）。
- 下調べのメモ（確認レベル [数字確認] [要旨確認] [書誌のみ]）があっても、記事に書く数字は**自分で原典を開いて照合したものだけ**。[書誌のみ] の文献は数字を書かない（存在の紹介まで）。
- 研究者の所属は原典のページで確かめて書く（取り違えやすい。例: 西谷ら 2005/2006 は和菓子の万寿や・マスヤ・三重大学で、亀田製菓ではない。亀田製菓の研究は Takei ら 2019）。

## 研究の確かさ（★3段階）

h1直下の `.evidence` に必ず付ける。
- ★★★: 煎餅・米菓で複数の研究（査読あり）が同じ向き
- ★★☆: 煎餅・米菓の研究はあるが少ない、または試験場の報告が中心
- ★☆☆: 煎餅の研究がほとんどなく、近い食品の研究からの推測。結果が分かれている

## 記事の構成（テンプレートの見出しの並びをそのまま使う）

結論（`.summary`、2〜3行） / 01 どんな研究か / 02 わかった数字 / 03 煎餅作りへの使い方 / 04 まだわからないこと / 05 よくある質問 / 出典。

- 大きい見出しは読者の問いにする（base.md「見出しは読者の質問にする」）。
- 02 は `.stats` に核心の数字2〜4個（条件つき）。比べる軸が2つ以上あるときだけ表（`.tbl`）。
- 03 は家庭で試せることを3つ。条件を1つだけ変えて比べる形にする（「蒸し時間だけを15分と30分で比べる」）。測り方（重さ・比容積・写真・擬音語の選択）を添える。火・やけど・焦げすぎの注意は必要な所に1文。
- 04 は省略しない。「煎餅で直接調べた研究は見つからなかった」を正直に書く。
- 本文は2,500〜4,000字（研究カード・表・FAQを含み、出典を除く）。
- 本文から同じメディアの記事へ2本以上リンク（`ls sites/senbei/` で存在を確認）。04の下の `.labnav` で `/tool/` と `/research/` へつなぐ。
- 記事を足したら、`media/senbei-pages.json` の研究一覧（`/research/`）で、その文献の行に記事リンクを足す。ツール（`/tool/`）の根拠リンクに使える記事なら、ツールの理由文のリンク先も記事に差し替える。

## 投稿データ（media.md 手順5）

`media/senbei-posts.json` の先頭に `{"slug","category"(材料|工程|食感|香りと味|感じ方|安全),"type":"study","date","title","summary"}` を追加する。タイトルは「問い。研究の答え」の形（最初の「？」までで問いとして読めるようにする）。

## 写真のルール

`python3 media/photo.py senbei {記事slug} "<英語の検索語>" --alt="<写っている物>"`。煎餅・米・餅・焼き網・醤油・乾燥中の食品など、物の写真に寄せる。店の看板・商品パッケージ・ブランド名が読める写真は使わない（売らない方針のため）。人の顔がはっきり写った写真は使わない。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 「世界一美味しい煎餅を作った」「最高のレシピ」など、目標を実績のように書くこと。
- 「科学的に証明」、出典にない「必ず」「すべて」。
- 商品名・店名の推奨、購入リンク、アフィリエイト。
- [書誌のみ] の文献の数字、検索結果の抜粋だけを根拠にした数字。
- 煎餅以外の研究を、対象を書かずに煎餅の結論として書くこと。
- 焦げや揚げ物の健康影響を煽る表現、病気の予防・治療をうたう表現。
- 絵文字、開発側の事情（課金・価格）。

## 自己検査（media.md 手順6に加えて）

- 研究者の所属・試作の枚数・米の種類・条件が原典どおりか。
- 結論の向きが原典と同じか（報告書の「考えられる」を「示された」に強めていないか）。
- 交絡（ほかに違っている条件）があるとき、それを書いたか。
- タイトルと説明文（description）には、研究が実際に測ったもの（機械の測定か人の評価か、何の項目か）と、主な限定（対象の食品・促進試験などの条件・交絡）を入れる。本文の但し書きだけで済ませない（検索結果とAIの引用はタイトルと説明文だけで読まれる）。写真は Commons の説明文まで見て、商品名・メーカー名が書かれたものは使わない。研究の対象と違う写真には、キャプションで一言断る。
- 組み合わせツール（`/tool/`）の理由文と、記事の結論が食い違っていないか。

## マス（テーマ×問い）で埋める（2026-10-20〜）

- 表は `media/senbei-matrix.json`（行=テーマ、列=仕組み/確かめる/作り方/数字/使う）。`python3 media/matrix.py senbei` で空きマスを見て、記事が最も少ないマスから書く。https のURL（/tool/・/flavor/ など）が入ったマスは埋まった扱いで、道具と同じ中身の記事は書かない
- 新しい記事は、公開済み（`media/senbei-posts.json`）と問い・結論が重ならないこと。近い記事は本文からリンクする
- 書いたら記事のslugを該当マスに足し、`python3 media/matrix.py senbei --check` を通す

## 公開前の自己点検（批判役で繰り返し出た指摘、2026-10-20）

1. **タイトル・説明文・結論が本文より強くない**: 外れ値や、条件の違う平均どうしの倍率を見出しに使わない。「だけ」「〜と無関係」と言い切るなら、原典で有意差を確かめて書く。AIや検索はタイトル・説明文・結論・FAQだけを引用するので、本文の注意書きを結論とFAQにも入れる
2. **物差しを混ぜない**: アンケート（好き）・購入（家計調査）・商品数（SEADICEの839件など）・官能評価（食べて評価）・装置の値（音の信号・硬さ）を書き分ける。装置の値を人の感じ方に換算しない
3. **研究の範囲を越えない**: 水溶液・スープ・別の食べ物・動物（マウス）・子どもの研究を、煎餅や大人に当てはめるときは「推定」と書く。煎餅で確かめた研究が無ければ、そうはっきり書く
4. **提案と研究を分ける**: 家での手順の数字（日数・量・回数）は「SEADICEの提案（研究の数字ではない）」と明記する。研究と方向が違う応用に「研究をまねた」と書かない
5. **企業の関与は結論の近くに**: メーカー（醤油・調味料・米菓）の研究者や、うま味調味料の会社の社員が著者のときは、社名と人数を結論の近く（結論の箇条書き）に書く。人数・所属は原典の著者欄で数え直す。利益相反の記載が無ければ「記載は確認できなかった」
6. **安全の記事は物差しを添える**: 焦げ（アクリルアミド）・塩分などは、公的機関の評価や目標量を同じ記事に入れ、不安をあおらず安心させすぎない。試作品の値は「市販品の値ではない」と数字のそばに書く。飲み込み・病気などは医療の助言にしない
7. **数字は原典で**: 要旨で確かめられない人数・数字は書かない。発表年・調査方法（人数・対象・年）を書く
