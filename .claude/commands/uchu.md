# 宇宙の研究 の記事ルール

基本は `.claude/commands/research.md` の「鉄則（信頼性）」と文章の質チェック（h2直下の結論・具体例）に従う。テンプレートは `.claude/commands/uchu-template.html`。以下は 宇宙の研究 固有の上書きルール。

## 立ち位置

**「わかっていること」と「まだわかっていないこと」を分けて書く。** 宇宙の話は、確かめられた観測・有力な仮説・想像が混ざって広まりやすい。このメディアはそれを分けて見せることで選ばれる。

- 研究カードには必ず確かさのラベルを付ける: `わかっている`（観測で確かめられ、研究者の間でほぼ合意）/ `有力な仮説`（証拠はあるが決着していない）/ `わかっていない`（まだ答えがない）。
- 04「まだわかっていないこと」は省略しない。1つ以上、具体的に書く（「〜はまだ観測されていない」「〜の説が対立している」）。
- 「宇宙の神秘」「驚愕」のような煽りや、SF・映画の描写を事実のように書かない。

## 読者

宇宙が好き・気になるが、専門知識はない人。中学生でもわかることを目標にする。

- 専門用語は初出で必ず言い換える（例: 「事象の地平面（光も出られなくなる境目）」）。
- 大きすぎる数字は身近なものに例える（例: 「地球をブラックホールにすると直径約1.8センチ」）。例えに使う数字も計算で確かめる。
- 1文は短く。1段落は3文まで。

## 出典

- **出典は4件以上、うち2件以上は査読論文**（RESEARCHと同じ基準）。論文は DOI か arXiv・NASA ADS の URL を載せる。
- 公的機関（NASA・ESA・JAXA・国立天文台・ESO・LIGO 等）の公式発表は補助として使ってよい。報道・まとめサイト・個人ブログだけを根拠にしない。
- 論文の実在は Crossref（`https://api.crossref.org/works/{DOI}`）で、雑誌・年・著者を確かめる。数値は論文の要旨か本文、または機関の公式発表で確かめたものだけを書く。

## 記事の構成（テンプレートの見出しの並び）

01 わかっていること / 02 どうやってわかったのか（研究カード） / 03 数字と例えでいうと（表） / 04 まだわかっていないこと / 05 関連する記事 / 06 よくある質問 / 出典。大きい見出しは、その節が答える読者の質問の形で書く。

- 05「関連する記事」は既存記事があれば `/{スラッグ}/` にリンクする。無ければこのブロックごと省く（存在しないリンクを書かない）。シミュレーター（`/simulator/`）に関係する記事（ビッグバン・宇宙の年齢・最初の星・宇宙の未来など）は、05 にシミュレーターへのリンクを1つ置く。

## 投稿データ（media.md 手順5）

`media/uchu-posts.json` の先頭に `{"slug","category"(設定のcategoriesのname),"type":"guide","date","title","summary"}` を追加する。

## 写真のルール

- `python3 media/photo.py uchu {記事slug} "<英語の検索語 2〜4語>"` を1回実行する。検索語は天体・望遠鏡・探査機に寄せる（例: "black hole M87", "James Webb telescope", "Andromeda galaxy"）。NASA・ESA の画像は Wikimedia Commons にパブリックドメインで多い。
- 想像図（イラスト）を使う場合は、記事内の写真の説明で「想像図」と書く。

## 星座と星空（カテゴリ seiza、2026-10-20〜）

エンタメとして読まれる分野。導入は「へえ」と思う話から楽しく入ってよいが、出典・確かさラベル・04まだわかっていないことのルールは同じ。

- 星座占い・誕生星座は「研究で確かめるとどうだったか」で書く（例: Carlson 1985 Nature の二重盲検）。信じる人や占いを楽しむ人を笑わない・見下さない。「当たらない」と断定するのでなく、研究の条件と結果をそのまま書く。
- 神話や星の和名は、国立天文台・IAU・博物館など公的な資料か査読論文で確かめる。ネットの星座サイトの言い伝えだけを根拠にしない。
- 星の位置・距離・明るさの数字は、IAU・ESA Gaia・国立天文台などで確かめる。
