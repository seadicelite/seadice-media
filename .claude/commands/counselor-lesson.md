# /counselor-lesson — 心理カウンセリング講座のレッスンを追加する

**先に `docs/study.md` を全部読む。** これが最上位のルール（レッスンの型・分量・検査・やらないこと）。このファイルと食い違うときは study.md を優先する。

対象: `media/counselor-course.json`（講座データ）。ページは共通エンジン `python3 media/study.py counselor` が生成する（旧 `counselor_pages.py` は使わない）。HTMLを手で編集しない。
品質基準として `docs/quality/base.md` と `docs/quality/course.md` も読む（学習サイト向け。写真は不要）。

## なぜ手元で実行するのか（最重要）

出典は e-Gov法令検索・厚生労働省・資格団体・学会・PubMed Central の論文などの一次情報で、クラウドの実行環境からはネットワーク制限で開けないことがある。出典を開いて確認できない状態では書かない方針なので、このコマンドは**手元のPCでだけ実行する**。クラウドのルーティンには登録しない。

## 目的

心理カウンセラーの仕事に関心がある人、大学・大学院で心理学を学ぶ前に全体像をつかみたい人が、無料でカウンセリングの基礎を順番に学べるようにする。AI検索で「心理カウンセラー 独学 無料 サイト」に名前が挙がることも狙う。

## 守ること（このサイト固有）

- **公式教材・団体公認と誤解される書き方をしない。** 公認心理師試験研修センター・日本臨床心理士資格認定協会・日本カウンセリング学会などとは無関係の独自教材である（about・免責に明記済み）。「公式」「対策講座」「合格」などの言葉を使わない。
- **試験の過去問・出題基準（ブループリント）の文言・市販テキストや問題集の文章と問題を写さない・言い換えない。** カリキュラムは大学の臨床心理学概論・心理学的支援法などの標準的な流れに沿わせ、本文と確認問題はすべてオリジナルにする。
- **読者の悩み相談にしない。** 本文は「支援する側として学ぶ」視点で書く。具体例は架空の人物（Aさん・Bさん）にし、実在の事例や個人を特定できる話を使わない。
- 心の不調を扱う章は `chapters[].care: true` にする（全レッスンに公的な相談先が出る）。自殺・自傷の手段や詳細な方法は書かない。
- 診断・治療を勧める書き方、特定の療法を万能とする書き方をしない。効果研究の数値は、研究の対象（例: 心の不調を抱える患者）と限界（相関研究であることなど）を本文に添える。

## 手順

1. `media/counselor-course.json` の `paused` は「クラウドの自動実行を止める」ためのフラグ。手元で実行するときは無視してよい。
2. 次に書くレッスンを決める: `chapters` を `no` の順に見て、`plan` のうち `lessons` にまだ無い最初の1件を書く。`$ARGUMENTS` に本数があれば、その本数だけ続けて書く（独立したレッスンはサブエージェントで並行して書き、最後にまとめて追加してよい）。
3. 調査: WebSearch / WebFetch / curl で出典を集める。
   - **使ってよい出典**: e-Gov法令検索（公認心理師法・医師法・個人情報保護法・労働安全衛生法・児童虐待防止法など。本文は `https://laws.e-gov.go.jp/api/1/lawdata/{法令ID}` で取れる）、厚生労働省（公認心理師の制度ページ、通知、「こころの耳」「まもろうよ こころ」「e-ヘルスネット」）、文部科学省（スクールカウンセラー等）、こども家庭庁、法務省、一般財団法人公認心理師試験研修センター（制度・登録者数などの事実のみ）、日本臨床心理士資格認定協会、日本カウンセリング学会・日本心理臨床学会・日本心理学会などの学会の公式情報（倫理綱領など）、NIMH・WHO・NHS などの海外公的機関、PubMed Central（pmc.ncbi.nlm.nih.gov）や J-STAGE で本文を確認できる査読論文、理論の原典（入手できる場合）。
   - apa.org は自動取得がブロックされることが多い。開けないページは出典にしない。
   - 個人ブログ・カウンセリングルームや講座会社の宣伝ページ・まとめサイト・検索結果のスニペットだけを根拠にしない。
   - 書く数値・年・人名・法律の条番号・定義は、開いた出典の本文で1件ずつ確認する。確認できないものは書かない。統計（登録者数など）は時点を本文に書く。
4. レッスンを `chapters[章].lessons` の末尾に追加する。形式は **docs/study.md 5章の新形式**（`question` / `review` / `sections` / `figure` / `apply` / `keep` / `terms` / `quiz`（1問以上 `apply: true`） / `sources`）。旧形式（`goals` / `summary`）では書かない。
   - 分量・文体は study.md 6章（本文600〜1000字、セクション1〜3、1段落3文まで、1文80字以内、keep ちょうど3、terms 3語まで、quiz 3問、太字は1セクション1か所、sources 2件以上、title 40字・description 120字まで）。
   - `review` は直前のレッスンの内容から新しく作る（章の最初のレッスンでは省いてよい）。`figure` は表（table）か図（svg）を1つ。
   - 専門用語は平易な言葉で先に言い、後から用語名を示す。後の章で詳しく扱う内容は先取りせず「第◯章で学びます」とつなぐ。
   - 具体例（架空の相談場面など）を最低1つ入れる。
   - 用語辞典 `media/counselor-glossary.json` に無い重要語は追加する（`{"id","term","en","field","def"("〇〇とは、△△のことです。"で始める)}`）。field は既存の分類（基本／資格と制度／倫理／援助関係と技法／面接とアセスメント／理論とアプローチ／心の健康と医療）から選ぶ。
5. `python3 media/study.py counselor --check` が `check ok` になるまで直し（旧形式レッスンの警告は出てよい。新形式のエラーは0にする）、`python3 media/study.py counselor` で生成する。
6. 公開前の自己検査（1つでも落ちたら直すか破棄する）:
   - 全出典URLを開き直し、本文の数値・年・人名・条番号・定義が出典に書かれていることを照合した。
   - 制度（資格・法令）が最新の内容か。改正があれば新しい方に合わせた。
   - quiz の正解 `a` が本文と一致し、正解以外が明確に誤り。
   - 試験の過去問・市販教材の文章や問題に似せていない。
   - 既存レッスンと内容が実質的に重複していない。
7. 公開: `git pull --rebase origin main` → `media/counselor-*.json` と `sites/counselor/` を `git add` → commit（`ゼロから学ぶ心理カウンセリング: レッスン {章}-{番号} {short}`）→ `git push origin main`。デプロイは GitHub Actions（配線済みの場合）。
8. 報告: レッスンURL（`https://counselor.seadice.win/course/{id}/`）、使った出典、講座の進捗。
