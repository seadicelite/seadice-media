# UMBRA の記事ルール

基本は `.claude/commands/research.md` の「読者」「鉄則（信頼性）」「手順」に従う。テンプレートは `.claude/commands/umbra-template.html`。以下は UMBRA 固有の追加・上書きルール。

## 立ち位置（最重要）

**「操る方法」ではなく「見抜く・守る」側に立つ。** Before→After は「操られる自分 → 見抜ける自分」。ダークな題材でも、読者が被害や騙しから身を守れる内容だけを書く。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 人を操る・洗脳する・騙す・支配するための具体的な手順や台本（悪用できる書き方）。
- 実在の人物・身近な人にラベルを貼らせる書き方（「〜な人はナルシスト」と断定・診断を促す表現）。診断は専門家の領域と明記する。
- 「必ず」「〜タイプの人は全員」等の断定、俗説の無批判な紹介（出典で確認できない通説は書かない）。
- 医療行為・法的助言の断定。被害が深刻な場合の相談先（専門機関・法テラス・警察相談 #9110・消費者ホットライン 188 等、記事の題材に合うもの）を必ず1つは入れる。ひきこもり系の「外部機関誘導なし」方針はこのメディアには適用しない。
- 絵文字。開発側の事情（課金・価格）。

## 出典

査読論文・メタ分析・大学・公的機関に限る。ダークトライアド等は原典（Paulhus & Williams 2002 など）の定義を確認してから使う。確認できなかった数値は書かない（research.md の鉄則どおり。一次ページが開けない場合は media.md の第二の情報源ルール）。

## 記事の種類ごとの構成（設定の types）

- **guide（深掘り、既定）**: テンプレートの構成を次の見出しに読み替える。01 何が起きているのか（悩みの正体）/ 02 研究でわかっていること / 03 見抜くサインと、身を守る小さな一歩 / 04 距離の取り方と相談先 / 05 よくある質問 / 出典。「この研究から考えた、こんなアプリ」（APP IDEA）は2026-09-23〜廃止（research.md参照）。
- news・term・weekly は、テンプレート未整備。設定の `types` にあっても、テンプレートができるまでは guide のみ作る。

## 投稿データ（media.md 手順5）

`media/umbra-posts.json` の先頭に `{"slug","category"(設定のcategoriesの name),"type":"guide","date","title","summary"}` を追加する。

## 公開

`publish` が `draft` の間は、media.md の draft 手順（ブランチ＋PR）に従い、main へは直接 push しない。

## 写真のルール（カテゴリ単位のプール運用。記事ごとの検索はしない）

- 画像は記事ごとに探さない。`media/umbra-images.json` にカテゴリ単位（`c-signs`/`c-gesture`/`c-marriage`/`c-redflag`/`c-game`/`c-breakup` 等）で1枚ずつ登録済みのプールを使い回す。画像本体は `sites/umbra/img/` にローカル保存してあるので、新しい記事のカードには同カテゴリの画像をそのまま使う。
- 新しいカテゴリを追加してプールに画像が無い場合だけ、CC0/CC BY-SA等の再配布可能な画像を1枚探して `sites/umbra/img/` に保存し、`media/umbra-images.json` に追記する（人物が写る写真は、嘘・危険な相手・被害・詐欺など誤解されかねない記事カテゴリでは避け、物・場所・道具に寄せる）。それでも見つからない・不適切なときは写真なしで公開してよい（カテゴリのアイコンが代わりに表示される）。
- 既存カテゴリの画像を記事ごとに差し替える必要はない。使い回しでよい。
