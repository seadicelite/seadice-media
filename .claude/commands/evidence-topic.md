# EVIDENCEアプリのトピック案を作る（記事を書いたあとに実行）

研究にもとづくアプリ「EVIDENCE」に載せる短いトピック（スワイプで読むカード3〜4枚）を、いま公開した記事の出典から1〜2本作る。アプリへの追加は人間が確認してから行うので、ここでは案をファイルに足すだけ。

## 作るかどうか
- 記事に、査読論文またはメタ分析・公的統計の出典があり、**その研究1本だけで話が完結する**ときだけ作る。作れないときは作らない（0本でよい）
- 1記事あたり最大2本。同じ研究を2本にしない

## 話題の種類と語り口
- 種類: よくある説（みんなが信じている説は本当？）／素朴な疑問（日常のなぜ）／研究紹介
- 友だちに話すように。「〜だよね」「実は」「〜らしい」はOK。1枚の本文は120字前後まで
- 「証明された」「絶対」「〜で治る」は使わない。数字・研究者・対象者は記事と論文どおりに書き、盛らない
- カードは3〜4枚、見出し（stage）は自由（例: よく聞く説／調べたこと／わかったこと／まだわからないこと）
- **最後か最後から2枚目に必ず「まだわからないこと」を入れる**（相関か因果か、対象者の偏り、実験室の話か、人数など）

## 事実の確認
- 数字は記事執筆時に読んだ論文本文と一致するものだけ。記事にない数字を足さない
- DOIは https://api.crossref.org/works/{DOI} で実在とタイトルを確かめる

## 出力
`media/evidence-candidates/{slug}.json`（slugはメディア名）に配列で追記する。ファイルがなければ `[]` から作る。json.dumps(ensure_ascii=False, indent=2) と末尾改行で保存。

```json
{
  "id": "{slug}-{記事slug}-{短い英語}",
  "category": "睡眠 などの短い分野名（既存の分野名があれば合わせる）",
  "kind": "よくある説 | 素朴な疑問 | 研究紹介",
  "themeColor": "#00FFD1",
  "sourceLabel": "著者 et al., \"論文タイトル\" (誌名, 年)",
  "sourceUrl": "https://doi.org/...",
  "studyType": "メタ分析 | ランダム化比較試験 | レビュー | 観察研究 | 実験（論文の方法を読んで決める）",
  "articleUrl": "公開した記事のURL",
  "articleSite": "メディア名（例: 悩みの科学）",
  "cards": [
    {"stage": "よく聞く説", "title": "...", "body": "..."},
    {"stage": "まだわからないこと", "title": "...", "body": "..."}
  ],
  "addedAt": "YYYY-MM-DD"
}
```

同じ sourceUrl の案がすでにファイルにあれば作らない。コミットには記事と同じコミットで `media/evidence-candidates/{slug}.json` も含める。
