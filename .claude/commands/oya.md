# 親が年をとったら の記事ルール

基本は `.claude/commands/research.md` の「読者」「鉄則（信頼性）」「手順」に従う。テンプレートは `.claude/commands/oya-template.html`。以下は親が年をとったら固有の追加・上書きルール。

## 立ち位置（最重要）

**読者は、70〜80代の親を持つ40〜60代の子ども。** 親の物忘れ・運転・転倒・ひとり暮らし・介護・お金の心配を、離れて暮らしながら抱えている人。高齢者本人ではなく「親のことで検索してきた子ども」に向けて書く。

**親の老いの疑問に、研究データから結論を先に答える。** 「親の物忘れは年のせい？」のような子どもが実際に検索する疑問をタイトルにし、冒頭で結論を言い切る（言い切れない場合は「研究ではまだ結論が出ていない」と言い切る）。

**親を説得する記事にしない。親の気持ちと自分で決める権利を大事にする。** 「やめさせる」「取り上げる」ではなく「一緒に決める」「親の気持ちを聞く」書き方にする。04「親と一緒にできること」は、親への声のかけ方・切り出し方を最低1つ入れる。

**わかっている度（★3段階）を必ず付ける。**
- ★★★: 複数の研究・メタ分析・公的機関の指針で結果がそろっている
- ★★☆: 研究はあるが、数が少ない・条件が限られる
- ★☆☆: 研究がほとんどない・結果が分かれている・間接的な研究からの推測

**何も売らない。** 見守りサービス・介護用品・サプリ・保険・老人ホーム紹介などの商品名やリンク、アフィリエイト、購入の勧めを一切書かない。公的な制度（介護保険、地域包括支援センター、運転経歴証明書など）の名前は書いてよい。

**Before→After** は「親の老いに気づいて、どうしたらいいかわからず不安な子ども → 根拠をもとに、親と一緒に次の一歩を決められる子ども」。

## テーマの選び方（検索される悩みから作る）

- **悩みを集める**: WebSearchで子ども世代の実際の悩みを調べる。見る場所の例: Yahoo!知恵袋・発言小町などのQ&A、検索サジェスト（「親 物忘れ 〜」「親 免許返納 〜」「親 一人暮らし 〜」等）、内閣府「高齢社会白書」、厚生労働省、警察庁、消費者庁、東京消防庁の統計。
- **ロングテールを半分以上**: 「親 認知症 チェック」のような短い語だけでなく「離れて暮らす母 電話で同じ話を何度もする」のような具体的な語も記事にする。
- **タイトルは検索語に寄せる**: 子どもが検索窓に打ちそうな言葉をタイトルの前半に入れる。専門用語をタイトルに入れない。語尾を固定しない（同じ語尾は直近10本中3本まで）。
- **研究で答えられるものだけ**: 確認できる研究や公的データが見つからないテーマは捨てて次へ。
- **重複を避ける**: 近いテーマの既存記事がある場合は、場面・状況を変えて切り口をはっきり分ける。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 商品名・サービス名・施設名、購入リンク、アフィリエイトリンク。
- 高齢者をひとまとめに「危険」「弱い」と描く表現、親や介護する子どもを責める表現、不安を煽る表現（「放っておくと手遅れ」等）。
- 研究の過大な一般化（相関を因果のように書く。相関研究は「関連があった」と書く）。海外の研究を日本の結論として書かない（国を必ず書く）。
- 認知症・病気の診断や治療・薬の助言。物忘れ・体の様子で気になる場合は「かかりつけ医」か「お住まいの地域の地域包括支援センター」を1つ添える。
- 制度の金額・条件は、何年度の数字かを必ず書き、厚生労働省など公式ページで確認できたものだけにする。
- 開発側の事情（課金・価格）。絵文字。

## 出典

**数字は条件まで原典と一致させる。** 「何歳以上の」「何年の」「どの国の」「どの分析で」といった条件も、原典の文と1つずつ照合する。要旨にない数字は、本文（Europe PMC の fullTextXML など）で確認できたものだけを使う。

老年医学・老年学・公衆衛生・リハビリテーション・交通安全研究の査読論文、メタ分析・システマティックレビュー（Cochrane 等）、WHO・厚生労働省・内閣府・警察庁・消費者庁・国立長寿医療研究センターなどの公的なデータと指針に限る。介護・見守りサービス事業者や保険会社の調査は出典にしない。

## 記事の構成（設定の types は guide のみ）

テンプレートの見出しをそのまま使う。01 結論から言うと / 02 研究とデータでわかっていること / 03 まだわかっていないこと / 04 親と一緒にできること / 05 よくある質問 / 出典。
- h1直下の `.evidence` に、わかっている度と「研究◯本・公的資料◯件を整理」を書く（本数は出典リストと一致させる）。
- 02の結論文の直後に `.stats`（核心の数字2〜4個、対象年齢・国・年を添える）を置く。
- 04は最低3つ。お金をかけずにできる行動と、親への声のかけ方（「 」で実際のセリフ例）を入れる。
- パンくずと BreadcrumbList の {{カテゴリID}} には media/oya.json の categories の id を入れる。
- 関連アプリ欄・APP IDEA は入れない（アプリ・ツールはメディアが育ってから作る方針）。

## 投稿データ（media.md 手順5）

`media/oya-posts.json` の先頭に `{"slug","category"(設定のcategoriesのname),"type":"guide","date","title","summary"}` を追加する。

## 写真のルール

`ledger.md` の写真のルールと同じ（`python3 media/photo.py oya {記事slug} "<検索語>"`、候補なしは検索語を変えて2〜3回まで再検索、使い回しは最終手段）。加えて、高齢者の顔がはっきり写った写真は使わない（物・場所・手元の写真に寄せる。例: "reading glasses table", "teapot cups", "handrail stairs", "car keys"）。

## 出典照合のチェック項目

記事を書くとき・点検するときは、`docs/quality/article.md` の「出典の正確さ」の8項目を1つずつ確認する。数字の確認だけで「照合済み」にしない。
