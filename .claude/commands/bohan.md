# 防犯 の記事ルール

基本は `.claude/commands/research.md` の「読者」「鉄則（信頼性）」「手順」に従う。テンプレートは `.claude/commands/bohan-template.html`。以下は 防犯 固有の追加・上書きルール。

## 立ち位置（最重要）

**何も売らない。** 防犯グッズ・防犯サービス・警備会社・保険などの商品名やリンク、アフィリエイト、購入の勧めを一切書かない。検索上位が業者の売り込みサイトばかりなので、「売らない」こと自体がこのメディアの信頼の根拠になる。対策はお金をかけずにできる行動・習慣・環境づくりを中心にする（鍵・補助錠など「設備」に触れる場合も、一般名と効果の根拠だけにとどめ、製品は挙げない）。

**記事の軸は「犯罪者の目線 → 読者ができること」（2026-10-01確定）。**
- 出発点は必ず「犯罪者はどう考え、どう動くか」（犯罪心理学・環境犯罪学の研究、警察の統計）。単なる統計紹介や防犯の一般論から始めない。
- 中心は読者ができること。03は最低3つ、お金をかけずにすぐできる行動にする。研究の紹介は、その行動の根拠という位置づけ。
- 犯人を詳しく描きすぎない。手口や心理は、対策を理解するのに必要な粒度まで（下の禁止事項と同じ）。

**犯罪者側の視点から読み解く。** 「犯罪者はどこを見て、何を嫌うのか」を研究・統計で先に示し、その裏返しとして対策を出す。Before→After は「漠然と不安な自分 → 何をすればいいか分かって落ち着いている自分」。

## 書いてはいけないこと（1つでも該当したら記事を破棄）

- 商品名・メーカー名・サービス名、購入リンク、アフィリエイトリンク。
- 恐怖を煽る表現（「あなたの家も狙われている」等）、被害者を責める表現（「鍵をかけないから悪い」等）。
- 犯罪の具体的な実行方法として使える手順（解錠の詳しい方法、侵入手順の詳細など）。手口は「対策を理解するのに必要な粒度」までにとどめる。
- 特定の地域・国籍・属性の人と犯罪を結びつける記述。
- 「これで絶対に防げる」等の断定。
- 被害やつきまとい等、深刻な状況に触れる場合は、110番（緊急時）または警察相談専用電話 #9110 を1つ添える。
- 開発側の事情（課金・価格）。絵文字。

## 出典

犯罪学・環境犯罪学・心理学の査読論文、メタ分析（Campbell Collaboration のシステマティックレビュー等）、警察庁・法務省（犯罪白書）・都道府県警の公的統計、大学・公的研究機関に限る。業者・警備会社が出した調査は出典にしない。確認できなかった数値は書かない（research.md の鉄則どおり）。統計を使うときは何年の数値かを必ず書く。

## 記事の構成（設定の types は guide のみ）

テンプレートの見出しをそのまま使う。01 犯罪者側から見ると何が起きているか / 02 研究と統計でわかっていること / 03 お金をかけずに今日からできること / 04 習慣にするコツ / 05 よくある質問 / 出典。02の結論文の直後に `.stats`（核心の数字2〜4個を大きく表示。quality.md「数字は埋もれさせない」）を置く。関連アプリ欄・APP IDEA は入れない（アプリはメディアが育ってから作る方針）。

## 投稿データ（media.md 手順5）

`media/bohan-posts.json` の先頭に `{"slug","category"(設定のcategoriesのname),"type":"guide","date","title","summary"}` を追加する。

## 公開

`publish` が `draft` の間は、media.md の draft 手順（ブランチ＋PR）に従い、main へは直接 push しない。

## 写真のルール

`ledger.md` の写真のルールと同じ（`python3 media/photo.py bohan {記事slug} "<検索語>"`、候補なしは検索語を変えて2〜3回まで再検索、使い回しは最終手段）。加えて、実在の住宅の表札・ナンバープレート・人の顔がはっきり写った写真は使わない。
