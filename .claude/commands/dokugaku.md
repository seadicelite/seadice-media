# /dokugaku — 独学のしかたを研究で確かめる記事

`$ARGUMENTS` について公開された研究を調べ、`sites/dokugaku/{スラッグ}/index.html` を作る。確認不要で最後まで実行し、記事URLを報告する。

## 読者（最優先）

資格・語学・仕事のスキルなどを**一人で学んでいる社会人や学生**。「覚えられない」「続かない」「やり方がわからない」と感じて検索してきた本人。研究者ではない。

- 専門用語は使わない。使うなら初出で平易に言い換える（例:「分散学習（間をあけて復習すること）」）。
- 冒頭は読者の悩みへの共感か、勉強法の通説への問いかけから入る。根性論や「意志が弱い」と責める書き方はしない。
- 「今日からできる一歩」は、次の勉強ですぐ試せる小さな行動にする（時間や回数を添える）。
- 特定の教材・塾・アプリ・サービスを勧めない（商品名で比較しない）。開発側の事情（課金・価格）は書かない。
- 1文を短く、段落を細かく、見出しは読者の言葉で。

## このメディアの立場

- よく言われる勉強法は「効く（研究で繰り返し確認）」「条件しだい」「当てにならない（研究で支持されない）」を切り分けて書く。
- 実験室の結果（大学生・短時間の課題）と、実際の独学（長期間・社会人）の違いを必ず1文で添える。
- 「〇〇すれば必ず覚えられる」「誰でも合格」などの断定・誇張はしない。

## 鉄則（信頼性）

- **確認できた出典だけを書く。** 論文・数値は WebFetch / WebSearch で実在と内容を確認してから使う。記憶や推測で補完しない。
- SEADICEは一次研究をしていない。「私たちの研究で」は禁止。「〇〇ら（年）の研究では」と第三者の研究として書く。
- 心身の不調（強い試験不安・抑うつ等）に触れるときは、診断や治療の助言をせず、つらさが続くときは相談先（こころの健康相談統一ダイヤル 0570-064-556 など）を1行添える。
- 絵文字禁止。

## 出典の基準（RESEARCHと同じ高さ）

- **出典は4件以上**、うち**2件以上は査読論文**（メタ分析・システマティックレビューを最優先）。
- 大学の広報記事・プレスリリースは補助としてのみ使う。研究者の解釈を、測定された結果として書かない。
- 修士・博士論文、プレプリント、調査会社のアンケートは「査読論文ではない」と明記するか、使わない。
- 有名な研究に再現の失敗や反論がある場合（例: マインドセット介入、学習スタイル）は、それも書く。

## 公開前の自己検査（1つでも当てはまれば直す。直せなければ公開しない）

この repo で実際に見つかった誤りのパターン。1つずつ確認する。

- 結論が出典と逆になっていないか（例:「効果を弱める」と書いたが、論文は「弱める効果は確認されなかった」）
- 出典のどこにもない数字を書いていないか
- 出典のリンク・DOIが、その論文そのものを指しているか（別の論文・関係ないページ・画像ページになっていないか）
- 別の研究・別の対象（年齢・国・科目）の結果を、この研究の結果として書いていないか
- 平均と中央値、確率とオッズ比、相関と因果を取り違えていないか
- 対象の説明（大学生か社会人か、何人か、どの国か）が出典と一致しているか

## 手順

1. **テーマ選び**: `$ARGUMENTS` が空なら `media/dokugaku.json` の `topicQueue` の先頭から、`ls sites/dokugaku/` の既存記事と被らないものを選ぶ。「〇〇な自分 → △△な自分」を一言で言える形に絞る。
2. **調査**: WebSearch で査読論文・メタ分析・レビュー・公的機関を日本語と英語で探す（目安4〜6件）。
3. **検証**: 各出典を WebFetch で開き、著者・年・雑誌名・対象・結果を確認する。全文が開けないときは Europe PMC（`https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:{doi}&resultType=core&format=json`）や出版社の要旨で確認する。
4. **執筆**: `.claude/commands/dokugaku-template.html` を元に書く。
   - スラッグは英小文字とハイフン。h1直後に結論1〜2文。各h2直下に120字以内の結論かリスト。
   - 構成: 導入 / 3行でわかる / 01 悩みの正体（または通説の中身） / 02 研究でわかっていること（研究カード） / 03 今日からできる小さな一歩 / 04 続けるためのコツ / 05 よくある質問 / 出典。
   - 具体的な数値・固有名詞を最低3箇所（確認済みのもののみ）。本文800〜1500字。
   - 出典は末尾に番号付きで、著者・年・タイトル・雑誌・DOIまたはURL。JSON-LD の `citation` にも入れる。
   - 日付は今日（`TZ=Asia/Tokyo date +%F`）。
5. **公開前の自己検査**（上の一覧）。
6. **配線・公開**: `.claude/commands/media.md` の手順5・7に従う。`media/dokugaku-posts.json` の先頭に `{"slug","category"(categoriesの name),"type":"guide","date","title","summary"(60字前後)}` を追加し、`python3 media/photo.py dokugaku {slug} "<英語の検索語>"`、`python3 media/build.py dokugaku`（写真は build.py が自サイト配信に切り替える）。
