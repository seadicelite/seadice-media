介護計画の立案・実施・評価とは？目標を立てて振り返る

このレッスンの問い

読む前に、答えを少しだけ予想してみてください。当たっていなくても大丈夫です。

レッスン11-2から

Q1. 前のレッスンの復習です。アセスメントで、利用者の思いや考えにあたる情報を何と呼んだでしょう？

答えを見る

正解: 2. 主観的情報
正解は「主観的情報」です。観察や記録から得る事実は客観的情報でした。

01立案：介護目標と、支援内容・方法を決める

介護計画の立案では、アセスメントで明らかになった生活課題を解決するための介護目標を立て、達成に必要な支援内容と方法を組み立てます。

日本介護福祉士養成施設協会の研修資料は、目標を2つに分けています。長期目標は、生活課題を解決して最終的に目指す生活の姿で、評価日は6か月〜1年程度です。短期目標は、長期目標に至る段階的な目標です。

目標は、現実的で達成でき、評価できるものにします。支援方法は、関わる介護福祉職の誰もが同じように実践できるよう、具体的に書きます。

介護計画は、本人や家族への説明と同意のもとで、チームが介護の方針や方法を共有するものです。利用者が納得でき、本人の意思を反映した計画であることが求められます。

02実施：計画をチームで共有し、日々の介護として行う

実施とは、立案した計画を実行することで、介護過程の展開における実施は日々の介護の実践そのものです。

資料は、チームの意識統一とサービス提供の態勢が、目標の達成度に影響すると述べています。利用者の反応を見ながら、安全に留意して行います。正しい介護技術を身につけて事故の防止に努めることも、資料は挙げています。

実施したときの利用者の様子は、事実のまま簡潔に記録します。この記録が、次の評価の材料になります。

03評価：目標の達成を確かめ、次につなげる

評価では、これまでのプロセスを振り返って目標が達成できているかを検証し、今後の介護をどうするかを検討します。

評価は、立案時に決めた評価日と、利用者の生活状態に変化が生じたときに行います。目標が達成されたら、今の方法を続ける必要があるかを判断します。

課題が完全に解決されたら、新たな生活課題について再アセスメントをします。達成されなかったときは、介護過程の各段階にさかのぼって見直します。

こうして介護過程は、終わりまで何度でも循環していきます。平成30年の養成課程の見直しでは、介護実習の教育内容に「介護過程の実践的展開」が加えられました。

あなたの場合は？

あなたが今年立てた目標を一つ思い出し、「いつまでに」「どうなったら達成か」を書き足してみましょう。

答えを書く必要はありません。少し思い浮かべるだけで、記憶に残りやすくなります。

覚えるのはこの3つ

  1. 長期目標は最終的に目指す生活の姿（評価日は6か月〜1年程度）、短期目標はそこへの段階
  2. 実施は日々の介護そのもの。チームで共有し、利用者の様子は事実のまま記録する
  3. 評価は評価日と状態の変化時。未達成なら各段階にさかのぼって見直す

TERMSこのレッスンの用語

長期目標Long-term goal

生活課題を解決して最終的に目指す生活の姿を示す目標で、評価日は6か月〜1年程度とされる。

短期目標Short-term goal

長期目標の達成に至るまでの段階的な目標。

再アセスメントReassessment

評価の結果をふまえて、新たな生活課題などについて改めてアセスメントを行うこと。

Q1. 研修資料が示す長期目標の説明として正しいものはどれでしょう？

正解は「最終的に目指す生活の姿」です。評価日は6か月〜1年程度で、そこへの段階が短期目標でした。

Q2. 介護過程の評価を行うタイミングとして、研修資料が示しているものはどれでしょう？

答えを見る

正解: 1. 立案時に決めた評価日と、生活状態に変化が生じたとき
ここがポイントです。決めた評価日に加えて、状態に変化があったときにも評価します。

Q3. あなたはEさんの担当です。「一人でトイレに行けるようになりたい」という短期目標の評価日に、目標は達成できていませんでした。介護過程に沿った対応はどれでしょう？

正解: 2. 実施・立案・アセスメントの各段階にさかのぼって、原因を見直す
