なぜ人は罪を犯すのか

曖昧な行動を「悪意」と読むと攻撃につながるのか。敵意帰属バイアスの111研究と、読み方の訓練の限界

約7分で読めます 出典照合済み（2026-11-03）

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

廊下で肩がぶつかった。後ろで誰かが笑った。こうした「わざとかどうか、わからない」場面を、悪意だと受け取りやすい人がいます。心理学ではこれを敵意帰属バイアスと呼びます。111研究・約2万9千人の子どもをまとめたメタ分析では、この癖と攻撃行動には「控えめだが確かな」関連がありました。ただし、読み方を変える訓練で攻撃が減るかは、まだはっきりしていません。

SUMMARY

  1. あいまいな行動を「悪意」と読む癖は、子どもの攻撃行動と関連する。111研究のまとめで効果量は d = 0.33 と控えめだった。
  2. 9か国1,299人の調査では、相手に悪意を読んだ場面で「やり返す」と答えた割合は19.6%。悪意なしと読んだ場面の3.7%の約5倍だった。
  3. 読み方を変える訓練は、読み方は変えても攻撃が減るとは限らない。29の比較試験のまとめで効果は小さかった。

01 どんな心の仕組みが働いているのかなぜ「わざとだ」と感じてしまうのか？

人は相手の行動を見ると、まず「なぜそうしたのか」を推し量ります。その推測が悪意の側に偏りやすいことを、敵意帰属バイアスと呼びます。

社会的な場面で、人は一瞬のうちに情報を処理しています。相手の表情や動きに気づき、その意図を解釈し、どう応じるかを選ぶ。この流れは「社会的情報処理モデル」と呼ばれ、子どもの攻撃行動の研究の土台になってきました。

ポイントは、同じ出来事でも解釈が分かれることです。ぶつかったのを「急いでいただけ」と読めば、やり返す理由はありません。「なめられた」と読めば、怒りがわき、仕返しの気持ちが出やすくなります。攻撃は出来事そのものより、出来事の読み方から始まる、というのがこの研究の出発点です。

仕返しの気持ちそのものについては「人はなぜ仕返しをしたくなるのか」で、怒りの扱い方については「怒りは「発散」すればおさまるのか」で取り上げています。

02 研究でわかっていること悪意に読む癖と攻撃は、どのくらい関係する？

関連は確かにありますが、強くはありません。2019年のメタ分析では平均の効果量が d = 0.33 で、著者ら自身が「控えめ」と表現しています。

Orobio de Castro ら（2002）[1]

41研究をまとめた2002年のメタ分析で、悪意に読む傾向と攻撃行動の間に、控えめだが確かな関連（d = 0.35）が見つかりました。関連は、攻撃がより深刻な子ども、仲間から拒まれている子ども、8〜12歳の子どもで強く出ました。

対象: 一般の子ども、とくに攻撃的な子ども、攻撃の問題で紹介された子どもを含む研究 ／ 限界: 研究ごとの結果のばらつきが大きく、知能を統制しなかった研究ほど関連が大きく出ていました。

Verhoef ら（2019）[2]

対象を111研究・29,272人に広げて見直すと、関連は平均 d = 0.33 でした。作り話の場面（文章・読み聞かせ・絵・動画など）を使う方法では d = 0.23〜0.44 にとどまり、実際の相手とのやりとりでは d = 1.33 と大きく出ました。感情が動く場面ほど、読み方の偏りが行動に表れやすいと著者らは解釈しています。

対象: 子どもを対象に、仲間とのやりとりの場面で調べた研究 ／ 限界: 効果量の約98%は作り話を使った研究によるもの。実際のやりとりの d = 1.33 は2研究・3個の効果量だけに基づきます。

Dodge ら（2015）[3]

9か国・12の地域の子ども1,299人を4年間追いました。子どもは、相手の意図がわからない10の場面の話を聞き、相手の意図と自分の反応を答えました。悪意があったと読んだ場面では19.6%が「やり返す」と答え、悪意なしと読んだ場面の3.7%を大きく上回りました。この傾向は12のすべての地域で見られました。

対象: 調査開始時の平均8.3歳、女子51% ／ 限界: 調査にもとづく相関の研究で、因果は証明できないと著者ら自身が書いています。前の年の攻撃的な行動が、翌年の悪意に読む癖を予測する逆向きの流れも見られました（著者らは、攻撃的にふるまうと周りから攻撃されやすくなるためと考えています）。

Penton-Voak ら（2013）・Haller ら（2022）[4][5]

あいまいな表情を「怒り」より「喜び」と読むよう練習させた実験では、大人の怒りの自己評価や、非行リスクの高い10代の攻撃行動が減りました。ところが、強いいらだちを抱える子ども44人を対象にした二重盲検の比較試験では、読み方は変わったのに、いらだちは偽の訓練と比べて一貫した改善を示しませんでした。

対象: 2022年の試験は、重いいらだちの診断を受けた子ども（訓練22人・偽の訓練22人、1週間に4回） ／ 限界: 2022年の試験は人数が少なく、追跡は訓練の2週間後まででした。

Ciesinski ら（2023）[6]

注意や解釈の偏りを直す訓練を調べた29の比較試験（2,334人）をまとめると、攻撃を減らす効果は平均 g = −0.23、怒りは g = −0.18 で、どちらも小さめでした。解釈の訓練に限ると攻撃に効果が見られましたが、訓練前の攻撃の程度を考慮すると、その効果ははっきりしなくなりました。

対象: 2013〜2023年に発表された比較試験 ／ 限界: 試験ごとに対象や訓練の内容が大きく違います。

03 よくある思い込みと、研究が示す実際「悪意に読む人は必ずキレる」は本当か？

本当ではありません。悪意に読む癖は攻撃の「起きやすさ」に関わる要因の1つで、それだけで攻撃が決まるわけではありません。

MYTH / 思い込み悪意に読む癖がある人は、たいていやり返す。
FACT / 研究では9か国の調査で、悪意があったと読んだ場面でも「やり返す」と答えたのは19.6%でした。残りの約8割の場面では、やり返す以外の反応を選んでいます。関連そのものも d = 0.33 と控えめです。
MYTH / 思い込み悪意に読むのは、嫌いな相手や前にもめた相手に対してだけだ。
FACT / 研究では2019年のメタ分析では、相手が知り合いかどうかに関係なく関連が見られました。著者らは、特定の相手への反応というより、場面を超えて働く「ものの見方の癖」に近いと考えています。
MYTH / 思い込み読み方を直す練習をすれば、攻撃はなくなる。
FACT / 研究では練習で読み方は変わりますが、攻撃やいらだちが減るかは研究で割れています。29試験のまとめでも効果は小さく、2022年の比較試験では症状の改善が確認されませんでした。

04 日常で生かせる視点この研究は、ふだんの人づきあいにどう生かせる？

「わざとだ」と感じたとき、それが事実ではなく自分の読みである可能性を思い出すことです。研究が示すのは、読み方が反応を左右するという点です。

  • あいまいな場面ほど、読みが入り込む。相手の意図がはっきりしない場面で強い怒りがわいたら、「たまたま」という読み方も成り立つか、一度考えてみる視点が役に立ちます。
  • 攻撃的な子どもの背景を見る。関連は仲間から拒まれている子どもで強く出ました。研究者は、仲間から拒まれる経験がこの癖を強める可能性を考えています。性格の問題だけで片づけられない面があります。
  • ニュースの「挑発された」に注意する。けんかやトラブルの報道で「相手が挑発した」と語られるとき、それは当事者の読みである場合があります。悪意の有無を判断する人も、自分の読みに偏りがないかを意識できます。行動の正当化のしかたは「人はどうやって自分の悪い行いを正当化するのか」も参考になります。

05よくある質問

敵意帰属バイアスとは何ですか？

相手の行動が「わざと」か「たまたま」かはっきりしない場面で、悪意があったと受け取りやすい傾向のことです。英語では hostile attribution bias と呼ばれ、子どもの攻撃行動の研究で40年以上調べられてきました。

大人にも敵意帰属バイアスはありますか？

大人を対象にした研究もあります。ただ、この記事で確認した2つの大きなメタ分析は、どちらも子どもが対象です。大人で同じ強さの関連があるかは、子どもの結果からそのまま言えません。

悪意に読む癖は、訓練で変えられますか？

あいまいな顔を「怒り」ではなく「喜び」と読むよう練習すると、読み方そのものは変わりやすいことがわかっています。一方で、攻撃やいらだちが減るかは研究で結果が割れており、29の比較試験をまとめた研究でも効果は小さめでした。
