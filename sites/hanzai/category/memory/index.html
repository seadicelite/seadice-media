記憶と目撃証言

目撃者の記憶はなぜ変わるのか。証言と記憶の心理学

記憶と目撃証言深掘り

体験していない出来事を「思い出す」ことはあるのか。「迷子の記憶」実験と、その再検証

子どもの頃の作り話を聞かされ、3割ほどが偽りの記憶を語った。ただし「はっきりした記憶」にまでなる人は15%ほどという見直しもある。

記憶と目撃証言深掘り

強いストレスを受けた目撃者の記憶は鮮明なのか。63の検証が示した「下がる」傾向

「怖い体験ほど鮮明に覚えている」とは限らない。メタ分析では、強いストレスで犯人の識別も細部の記憶も下がっていた。

記憶と目撃証言深掘り

凶器があると犯人の顔を覚えていないのか。目が奪われる「凶器注目効果」の研究

凶器があると目撃者の記憶は落ちる。ただし犯人を選ぶ精度への影響は小さく、服装など細部の記述への影響の方が大きかった。

記憶と目撃証言深掘り

ディープフェイクは記憶を書き換えるのか。偽の映画を「見た」人は約半数、でも文章だけでも同じだった

存在しない映画のリメイクを見た人の49%が偽の記憶を持ったが、文章だけで伝えても同じだった。偽の映像と記憶の研究

記憶と目撃証言深掘り

見慣れない集団の顔は見分けにくいのはなぜか。「他人種効果」は生まれつきではなく経験で変わる

見慣れない集団の顔は見分けにくく、見間違いも増える。差は経験で生まれ、子ども時代の環境で逆転することもある。

記憶と目撃証言深掘り

「自信がある証言」は正しいのか。最初の確信は当てになり、法廷での確信は当てにならない理由

法廷での目撃者の確信は当てにならない。だが適切な面通しで最初に示された確信は、正確さのよい目安になることがわかってきた。

記憶と目撃証言深掘り

子どもの証言はどこまで信頼できるか。決め手は年齢より「聞き方」だった

幼い子どもは誘導に影響されやすいが、多くを正しく思い出せる。証言の質は、大人の聞き方で大きく変わる。

記憶と目撃証言深掘り

面割りは「一度に見せる」か「一人ずつ見せる」か。見せ方で目撃者の犯人選びはどう変わるのか

面割りを一人ずつ見せると誤りは減るが、犯人を当てる率も下がる。どちらが優れるかは研究者の間でも見直しが続いている。

記憶と目撃証言深掘り

質問の言葉ひとつで記憶は変わるのか。「激突」と聞かれた人は、なかったガラス片を思い出した

「激突した」と聞かれた人は速度を高く見積もり、32%がなかったガラス片を思い出した。後から入った情報で記憶は書き換わりうる。

記憶と目撃証言深掘り

衝撃的な出来事の記憶は正確なのか。9.11の記憶を10年追った研究が示した「確信は高いまま、中身は変わる」

衝撃的なニュースを知った瞬間の記憶は、1年後に最初の回答と一致したのは平均63%。中身は変わっても、本人の確信は10年間高いままだった。
