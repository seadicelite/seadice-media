記憶と目撃証言

体験していない出来事を「思い出す」ことはあるのか。「迷子の記憶」実験と、その再検証

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

子どもの頃にショッピングモールで迷子になった。そんな体験をしていないのに、話を聞かされるうちに「思い出して」しまうことはあるのでしょうか。1995年に発表された「迷子の記憶」実験は、偽りの記憶の研究を大きく広げました。その後の再現と見直しから、どこまで言えるのかを見ていきます。

SUMMARY

  1. 1995年の「迷子の記憶」実験を5倍の人数（123人）で再現した2023年の研究では、35%が迷子になった偽りの記憶を語った。元の研究では25%だった。
  2. 偽りの記憶を植えつける8つの研究（423人）の記録を同じ基準で採点し直した2017年の分析では、30.4%が偽りの記憶、さらに23%が出来事をある程度受け入れたと判定された。
  3. 一方、2017年の系統的レビューでは、何らかの「思い出す感覚」が生じたのは平均47%だが、本人も完全な記憶と評価しそうなのは15%にとどまった。

01どんな心の仕組みが働いているのか

記憶は、実際の体験だけでなく、人から聞いた話や頭の中で思い描いた場面からも作られます。思い描いた場面が、いつのまにか「体験した記憶」として感じられることがあります。

「迷子の記憶」実験では、参加者の家族から子どもの頃の本当の出来事を聞き取り、そこに作り話をひとつ混ぜて参加者に示しました。参加者は、それぞれの出来事について思い出せることを話します。

この手法は、人の記憶に出来事をまるごと植えつけられるかを調べるものです。何度も思い出そうとするうちに、作り話の場面に細部や感情が加わっていくことがあります。

02研究でわかっていること

作り話を聞かされると、3割ほどの人が偽りの記憶を語ることは、再現研究でも確かめられています。ただし、どこからを「記憶」と呼ぶかで割合は大きく変わります。

35%迷子になった偽りの記憶を語った人（2023年の再現研究・123人）
30.4%偽りの記憶と判定された人（8研究・423人の再分析・2017年）
15%本人も完全な記憶と評価しそうな人（系統的レビュー・2017年）

Murphyら（2023）[1]

1995年の「迷子の記憶」実験を、事前に分析計画を登録したうえで、元の5倍の123人で再現した。年上の家族から聞いた本当の出来事と作り話について、アンケートと2回の面接で話してもらった。35%が子どもの頃に迷子になった偽りの記憶を語ったと判定された（元の研究では25%）。模擬陪審員の多くも、作り話の出来事が本当にあったと信じた。

対象: 123人の参加者 ／ 限界: 植えつけた出来事は迷子の1種類のみ。

Scoboriaら（2017）[2]

偽りの記憶を植えつける8つの研究（423人）の面接記録を、7つの基準で採点し直した（メガ分析）。30.4%が偽りの記憶、さらに23%が出来事をある程度受け入れたと判定された。自分に関係する情報を使い、想像させる手順があり、写真を使わない条件では、偽りの記憶の割合は46.1%だった。

対象: 8研究の参加者423人 ／ 限界: 研究者が記録を採点したもので、本人の感じ方とは一致しない場合がある。

BrewinとAndrews（2017）[3]

子どもの頃の偽りの出来事を大人に植えつける3種類の研究を見直した系統的レビュー。想像させる方法や偽りの結果を伝える方法では、出来事があったと信じる度合いは少し上がるだけだった。植えつけ研究では、何らかの思い出す感覚が平均47%に生じたが、完全な記憶と評価されそうなのは15%だった。偽りの記憶へのかかりやすさは、言われてきたより限られるとしている。

対象: 3種類の研究方法の文献 ／ 限界: 何を「記憶」と数えるかの定義に左右される。

03よくある思い込みと、研究が示す実際

「人の記憶は簡単に作り変えられる」も、「偽りの記憶はめったに起きない」も言いすぎです。起きることは確かですが、その割合は数え方で変わります。

MYTH / 思い込み体験していないことを思い出すなど、ありえない。
FACT / 研究では作り話を聞かされた人の3割ほどが偽りの記憶を語りました。2023年の再現研究でも35%でした。
MYTH / 思い込み誰でも簡単に偽りの記憶を植えつけられる。
FACT / 研究では本人も完全な記憶と評価しそうなのは15%ほどという見直しがあり、多くの人は受け入れきりません。
MYTH / 思い込み細かく感情を込めて語られる記憶は、本物の体験だ。
FACT / 研究では模擬陪審員の多くは、作り話の出来事も本当にあったと信じました。語りの詳しさだけでは見分けられません。

04日常で生かせる視点

記憶の詳しさや本人の確信だけでは、本当に体験したことかどうかは判断できない、と知っておくことが大切です。

  • 昔の出来事についての証言が報道されたら、その記憶がどんな聞き取りや話し合いを経て出てきたかに目を向ける。
  • 裁判員として古い出来事の証言を聞くときは、語りの詳しさより、記録やほかの証拠と合っているかを確かめる。
  • 家族の思い出話で記憶が食い違っても、どちらかがうそをついているとは限らない。聞いた話が記憶に混ざることがあります。

05よくある質問

偽りの記憶とは何ですか

実際には体験していない出来事を、体験したこととして思い出してしまう記憶のことです。人から聞いた話や、思い描いた場面がもとになります。

「迷子の記憶」実験は再現されましたか

2023年に123人で再現され、35%が迷子になった偽りの記憶を語りました。1995年の元の研究では25%でした。

偽りの記憶はどのくらいの人に起きますか

8研究を再分析した2017年の研究では30.4%でした。ただし、本人も完全な記憶と評価しそうなのは15%ほどという見直しもあります。
