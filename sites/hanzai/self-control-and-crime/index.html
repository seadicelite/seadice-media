なぜ人は罪を犯すのか

「我慢できない人」が罪を犯すのか。セルフコントロール理論を99件の研究で確かめると

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「我慢が苦手な人ほど、罪を犯しやすい」。これは犯罪学で最も多く検証された理論の1つ、セルフコントロール理論の考え方です。本当にそう言えるのか、どこまで言えるのかを、大きな研究のまとめから見ていきます。

SUMMARY

  1. Pratt と Cullen（2000）のメタ分析では、測り方が違っても、自制心の低さは犯罪の重要な予測因子だった。ただし長期の追跡研究では効果が弱かった。
  2. 2000〜2010年の研究99件をまとめたメタ分析では、自制心の低さと逸脱行動の相関は、ある時点の調査でr=0.415、追跡研究でr=0.345だった。
  3. 約1,000人を生まれてから32歳まで追った研究では、子ども期の自制心が低いほど、大人になってからの犯罪が多かった。知能や家庭の経済状況を考慮しても同じ傾向だった。

01どんな心の仕組みが働いているのか

目先の得を優先し、後の損を考えにくい傾向が、犯罪にも、似た行動にも表れるという考え方です。

セルフコントロール（自制心）とは、すぐに得られる楽しさや得を我慢し、先のことを考えて行動する力のことです。犯罪学者のGottfredsonとHirschiは1990年に「犯罪の一般理論」を発表しました。自制心の低さが、さまざまな犯罪の共通の原因になると考えたのです。

この理論は、自制心が低い人は犯罪だけでなく、犯罪に似た危険な行動もしやすいと予想しました。犯罪の種類ごとに別々の原因を探すのではなく、1つの共通の原因で広く説明しようとした点が特徴です。

02研究でわかっていること

自制心の低さと犯罪の関係は、多くの研究で一貫して確認されています。ただし、ほかの要因も同時に働いています。

99件2017年のメタ分析がまとめた研究の数

Pratt と Cullen（2000）[1]

理論を検証した研究をまとめた初めての大きなメタ分析。測り方が違っても、自制心の低さは犯罪や似た行動の重要な予測因子だった。一方で、追跡研究では効果が弱まった。また、仲間から悪いことを学ぶという別の理論の要因も、自制心とは別に効いていた。

対象: 理論を検証した既存の研究 ／ 限界: 多くはある時点だけの調査。

Vazsonyiら（2017）[2]

2000〜2010年の研究99件をまとめた。自制心の低さと逸脱行動の相関は、ある時点の調査でr=0.415、追跡研究でr=0.345だった。両者の差は統計的に意味のある差ではなかった。男性が多い研究、年齢が高い集団、自己申告の研究では効果がやや弱かった。

対象: 99件の研究 ／ 限界: 相関であり、原因と結果を直接示すものではない。

Moffittら（2011）[3]

約1,000人の子どもを生まれてから32歳まで追跡した。子ども期の自制心が低いほど、健康、お金、犯罪の面で大人になってからの結果が悪かった。知能や家庭の社会階層を考慮しても関係は残った。別の約500組のきょうだいでも、自制心が低いほうが結果が悪かった。

対象: 約1,000人の出生コホートと約500組のきょうだい ／ 限界: 観察研究で、自制心を高めれば犯罪が減ることまでは示していない。

03よくある思い込みと、研究が示す実際

自制心は大事な要因ですが、「我慢できない人だけが罪を犯す」わけではありません。

MYTH / 思い込み犯罪をするのは、我慢が足りない人だけだ。
FACT / 研究では自制心の低さは重要な要因ですが、仲間や環境など、ほかの要因も別に働いていることが示されています。
MYTH / 思い込み自制心が低い人は、必ず犯罪をする。
FACT / 研究では相関はr=0.35〜0.42ほどで、自制心が低くても犯罪をしない人はたくさんいます。
MYTH / 思い込み自制心と犯罪の関係は、時間をおいて追うと消えてしまう。
FACT / 研究では2000年のメタ分析では追跡研究で効果が弱まりましたが、2017年のメタ分析では、追跡研究でもr=0.345の関係があり、ある時点の調査と差はありませんでした。

04日常で生かせる視点

一人の性格だけで犯罪を説明しない見方が、ニュースや人間関係を冷静に見る助けになります。

  • 事件の報道で「衝動的な性格」と説明されたら、環境や人間関係など、ほかの要因も考えてみる。
  • 裁判員として判断するときは、相関がある要因と、その人が必ずそうするという話を分けて考える。
  • 身近な人の衝動的な行動には、責めるより、先の見通しを一緒に立てる手助けが役に立つことがある。

05よくある質問

セルフコントロール理論とは何ですか

1990年にGottfredsonとHirschiが唱えた理論で、自制心の低さがさまざまな犯罪や似た行動の共通の原因になると考えます。

自制心と犯罪の関係はどれくらい強いのですか

2017年のメタ分析では相関がr=0.35〜0.42でした。社会科学では比較的はっきりした関係ですが、これだけで犯罪が決まるわけではありません。

子どものころの自制心は、大人になってからにも関係しますか

約1,000人を32歳まで追った研究では、子ども期の自制心が低いほど大人になってからの犯罪が多く、知能や家庭の状況を考慮しても関係が残りました。
