記憶と目撃証言

見慣れない集団の顔は見分けにくいのはなぜか。「他人種効果」は生まれつきではなく経験で変わる

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「外国の俳優の顔が見分けにくい」と感じたことはありませんか。これは誰にでも起きる知覚のくせで、研究では「他人種効果」と呼ばれます。目撃証言では、このくせが見間違いにつながることがあります。どこから来るのでしょうか。

SUMMARY

  1. 39の論文・91のサンプル・約5,000人を分析したメタ分析では、見慣れた集団の顔は正しく思い出されやすく、見ていない顔を「見た」と答える誤りも少なかった。
  2. 生後3か月の乳児はどの集団の顔も見分けられたが、9か月になると、ふだん見ている集団の顔だけを見分けるようになった。
  3. 3〜9歳で欧州の家庭の養子になった韓国生まれの大人は、育った環境の顔の方を見分けやすく、韓国で育った人と逆の傾向を示した。

01どんな心の仕組みが働いているのか

顔を見分ける力は、ふだん見ている顔に合わせて磨かれます。そのため、なじみの少ない顔では細かな違いに気づきにくくなります。

私たちは毎日見る顔から、どこに違いが出やすいかを学んでいます。これを知覚学習（経験で見る力が育つこと）と呼びます。

見慣れない集団の顔では、この学習が足りません。そのため「みんな似て見える」と感じやすくなります。これは相手の集団の特徴ではなく、見る側の経験の量によるものです。

02研究でわかっていること

差は生まれつきではなく、経験で作られます。乳児期に現れ、子ども時代の環境が変われば入れ替わることもあります。

約5,000人メタ分析に含まれた参加者（39論文・91サンプル、2001年）
9か月ふだん見る集団の顔だけを見分けるようになった乳児の月齢（2007年）
3〜9歳養子として育つ環境が変わり、差が逆転した人たちの年齢（2005年）

Meissner・Brigham（2001）[1]

30年分の研究から、39の論文・91のサンプル・約5,000人のデータをまとめたメタ分析。見慣れた集団の顔は、正しく「見た」と答える率が高く、見ていない顔を「見た」と答える誤りが少なかった。見慣れない顔ではその逆で、見間違いが増えることを意味する。研究者は、知覚学習の違いが関わると論じた。

対象: 実験室の顔の記憶課題 ／ 限界: 写真を覚える実験が中心で、実際の事件とは条件が違う。

Kellyら（2007）[2]

白人の乳児に、自分の集団を含む4つの集団の顔を見せた。生後3か月ではすべての集団の顔を見分けられた。6か月では2つの集団に、9か月では自分の周りの集団の顔だけに絞られた。研究者は、乳児期に見る顔がその後の見分ける力を形づくると考えている。

対象: 生後3・6・9か月の乳児 ／ 限界: 白人の乳児だけを調べている。

Sangrigoliら（2005）[3]

3〜9歳で欧州の家庭の養子になった韓国生まれの大人に、欧州系とアジア系の顔の記憶課題を行った。結果はフランス人の比較群とまったく同じで、欧州系の顔の方をよく見分けた。韓国で育った比較群は逆の傾向だった。子ども時代の経験で差が入れ替わることを示している。

対象: 養子の大人と2つの比較群 ／ 限界: 大人になってからの経験の効果は、この研究ではわからない。

03よくある思い込みと、研究が示す実際

「あの集団の人は顔が似ている」のではありません。見る側の経験が少ないと、誰でも見分けにくくなるのです。

MYTH / 思い込みある集団の人たちは、実際に顔が似ている。
FACT / 研究では差は見る側に生じます。韓国で育った人と欧州で育った人では、見分けやすい顔が逆になりました。
MYTH / 思い込み顔の見分けやすさは生まれつき決まっている。
FACT / 研究では生後3か月ではどの顔も見分けられました。差は経験の中で9か月ごろまでに生まれます。
MYTH / 思い込み自信を持って覚えた顔なら、相手が誰でも正確だ。
FACT / 研究では見慣れない集団の顔では、見ていない顔を「見た」と答える誤りが増えます。

04日常で生かせる視点

「見分けにくい」のは自分の経験の偏りだと知るだけで、決めつけを一歩手前で止められます。

  • ニュースで目撃者と相手がなじみの薄い関係のときは、見間違いの可能性も頭に置いて読む。
  • 裁判員になったら、目撃者がその集団の顔にどれだけ接してきたかも考える材料にする。
  • 日常で人を取り違えたときは、相手ではなく自分の経験の差だと考え、素直に謝る。

05よくある質問

他人種効果とは何ですか

なじみの薄い集団の顔を、なじみのある集団の顔より見分けにくく、覚えにくい傾向です。誰にでも起きる知覚のくせです。

なぜ見慣れない顔は見分けにくいのですか

ふだん見る顔から違いの見つけ方を学んでいるためです。見る機会が少ない顔では、その学習が足りなくなります。

この傾向は変えられますか

子ども時代に育つ環境が変わると入れ替わった研究があります。大人になってからどこまで変わるかは、まだよくわかっていません。
