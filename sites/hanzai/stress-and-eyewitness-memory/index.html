記憶と目撃証言

強いストレスを受けた目撃者の記憶は鮮明なのか。63の検証が示した「下がる」傾向

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「あんなに怖かったのだから、はっきり覚えている」。事件の目撃者がそう話すと、説得力があるように感じます。では実際に、強いストレスは目撃者の記憶を確かなものにするのでしょうか。研究をまとめた論文から見ていきます。

SUMMARY

  1. 2004年のメタ分析は、犯人の識別を調べた27の検証と、出来事の細部の記憶を調べた36の検証をまとめた。
  2. 強いストレスがあると、犯人を正しく識別する割合も、細部を正しく思い出す正確さも下がった。影響の大きさ（効果量）はどちらも-0.31だった。
  3. その下がり方は、面通しに犯人がいる場合や、犯罪を演じて見せる実験で、特に大きかった。

01どんな心の仕組みが働いているのか

強いストレスを受けると、体は危険に備えた状態になります。そのとき注意は目の前の脅威に集まり、周りの細かい情報は取り込みにくくなると考えられています。

一方で、感情が強く動いた出来事は、印象に残りやすいとも言われます。1992年の総説は、「ストレスは記憶を悪くする」という見方は単純すぎると指摘しました。

出来事の種類、どの部分の記憶か、いつ確かめるかによって、結果が変わるためです。どの種類の細部を思い出すかによっても、結果に違いが出ます。

02研究でわかっていること

目撃証言の研究をまとめると、強いストレスは犯人の識別と細部の記憶の両方を下げる傾向があります。ただし、条件によって結果は変わります。

632004年のメタ分析にまとめられた検証の数（識別27＋細部の記憶36）
-0.31強いストレスが犯人の識別の正答に与えた影響の大きさ（効果量・2004年）
-0.31強いストレスが出来事の記憶の正確さに与えた影響の大きさ（効果量・2004年）

Deffenbacherら（2004）[1]

30年分の研究から、犯人の識別を調べた27の検証と、出来事の細部の記憶を調べた36の検証をまとめたメタ分析。強いストレスがあると、犯人を正しく選ぶ割合も、細部を正しく思い出す正確さも下がった。影響の大きさはどちらも-0.31だった。面通しに本当の犯人がいる場合や、目の前で犯罪を演じる実験では、下がり方が特に大きかった。

対象: 実験的な検証63件 ／ 限界: 倫理上、実際の事件ほどの強いストレスは実験で再現できない。

Christianson（1992）[2]

感情的なストレスと目撃記憶の研究を見直した総説。「ストレスで処理できる量が減り、記憶が悪くなる」という見方は単純すぎると指摘した。出来事の種類、細部の種類、確かめる時期、思い出す手がかりによって、結果が大きく変わることを示した。

対象: 実験室と実生活の研究の総説 ／ 限界: 1992年までの研究に基づく。

Marrら（2021）[3]

目撃証言の研究と、記憶の基礎研究とで、ストレスの影響について異なる結論が出がちな理由を整理した総説。ストレスの与え方、本当にストレスがかかったかの確認方法、記憶を確かめるまでの間隔など、研究方法の違いが結果を分けていると指摘した。生理的な指標でストレスを確かめることなどを提案している。

対象: 研究方法の総説 ／ 限界: 新しいデータではなく、要旨のみ確認。

03よくある思い込みと、研究が示す実際

「怖かったからこそ鮮明に覚えている」は、研究の全体像とは合いません。強いストレスは、記憶をむしろ下げる傾向があります。

MYTH / 思い込み怖い体験ほど、細部まで鮮明に覚えている。
FACT / 研究では63の検証をまとめたメタ分析では、強いストレスで犯人の識別も細部の記憶も下がっていました。
MYTH / 思い込みストレスは記憶を悪くする、で話は終わる。
FACT / 研究ではどの部分の記憶か、いつ確かめるかで結果は変わります。単純に言い切れないという指摘もあります。
MYTH / 思い込み本人が「はっきり覚えている」と言えば、記憶は正確だ。
FACT / 研究では鮮明に感じることと、正確であることは別です。ストレスの強い場面では、とくに慎重に扱う必要があります。

04日常で生かせる視点

怖い体験の記憶は、本人の感じ方と実際の正確さがずれることがある、と知っておくことが役立ちます。

  • 事件の報道で「恐怖の中で犯人の顔を見た」という証言を見たら、強いストレスは識別を下げやすいことを思い出す。
  • 裁判員として証言を聞くときは、記憶の鮮明さよりも、最初に記録された内容や、ほかの証拠との一致に目を向ける。
  • 怖い体験をした人の話が細部で食い違っても、うそと決めつけない。ストレスで細部が抜け落ちるのは自然なことです。

05よくある質問

強いストレスを受けると記憶はよくなりますか

目撃証言の研究をまとめた2004年のメタ分析では、強いストレスで犯人の識別も出来事の記憶も下がる傾向がありました。

どのくらい記憶が下がるのですか

影響の大きさ（効果量）は、犯人の識別でも出来事の記憶でも-0.31でした。面通しに本当の犯人がいる場合に特に大きく下がりました。

なぜ研究によって結論が違うのですか

ストレスの与え方、ストレスの確かめ方、記憶を調べるまでの間隔など、研究方法の違いが結果を分けていると指摘されています。
