記憶と目撃証言

質問の言葉ひとつで記憶は変わるのか。「激突」と聞かれた人は、なかったガラス片を思い出した

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

事故を見た人に「車が激突したとき、何キロ出ていましたか」と聞くと、答えは変わるのでしょうか。目撃証言は、見た直後の記憶だけでなく、その後に聞いた言葉や情報の影響も受けます。この現象は「事後情報効果」と呼ばれ、50年近く研究されてきました。

SUMMARY

  1. 1974年の実験では、「激突した」と聞かれた人の速度の見積もりは平均40.8マイル（約66km）で、「接触した」と聞かれた人の31.8マイル（約51km）より高かった。
  2. 1週間後、「激突した」と聞かれた人の32%が、映像になかった割れたガラスを「見た」と答えた。「ぶつかった」と聞かれた人では14%だった。
  3. 25研究・155の効果量をまとめたメタ分析では、後から「誤った情報が混じっていた」と警告すると、事後情報効果は平均して半分以下に減った。

01どんな心の仕組みが働いているのか

記憶はビデオの録画ではありません。思い出すたびに組み立て直されるため、後から入った言葉や情報が、もとの記憶に混ざることがあります。

事後情報効果とは、出来事の後に誤った情報にふれることで、出来事の記憶がゆがむ現象です。たとえば「止まれ」の標識を「ゆずれ」の標識として思い出したり、なかった物を「見た」と答えたりします。

この研究の出発点のひとつが、交通事故の映像を使った1974年の実験です。質問の動詞をひとつ変えただけで、速度の見積もりと、1週間後の記憶が変わりました。

02研究でわかっていること

質問の言葉や後から得た情報で、目撃者の記憶がゆがむことは、数百の研究で確かめられています。一方で、後からの警告で影響を減らせることもわかっています。

32%「激突した」と聞かれ、なかったガラス片を見たと答えた人（1974年・50人中16人）
14%「ぶつかった」と聞かれ、同じように答えた人（1974年・50人中7人）
半分以下後からの警告で小さくなった事後情報効果の大きさ（25研究のメタ分析・2014年）

LoftusとPalmer（1974）[1]

学生45人に交通事故の映像を見せ、速度を質問した。「激突した」と聞くと平均40.8マイル、「接触した」では31.8マイルと答えた。実際に時速20〜40マイルで衝突させた映像でも、見積もりは36〜40マイル前後で、本当の速度はほとんど反映されなかった。別の150人の実験では、1週間後に「割れたガラスを見たか」と聞くと、「激突した」群の32%、「ぶつかった」群の14%、質問なし群の12%が「見た」と答えた。映像にガラス片はなかった。

対象: 米国の大学生 ／ 限界: 短い事故映像を見る実験で、実際の事件の目撃とは異なる。

Loftus（2005）[2]

30年分の事後情報効果の研究をまとめた総説。割れたガラスのような存在しない物、「止まれ」と「ゆずれ」の標識の入れ替えなど、数百の研究で記憶のゆがみが確認された。誤った情報への警告が効くのは限られた条件のときだけだと述べている。また、ゆがみやすさには個人差があることも紹介している。

対象: 実験研究の総説 ／ 限界: 研究の多くは大学生を対象にした実験室の研究。

BlankとLaunay（2014）[3]

誤った情報を与えた後に「さっきの説明には誤りが含まれていた」と警告する研究25件（155の効果量）をまとめたメタ分析。警告によって事後情報効果は平均して半分以下に小さくなった。警告で正しい記憶の成績が下がることはほとんどなかった。

対象: 実験研究25件 ／ 限界: 警告で効果は消えきらず、実際の捜査での効果は検証が足りない。

03よくある思い込みと、研究が示す実際

「目撃した本人の記憶だから確か」とは言えません。ただ、記憶が一度ゆがむと元に戻らない、というわけでもありません。

MYTH / 思い込み自分の目で見たことは、そのまま正確に覚えている。
FACT / 研究では記憶は思い出すたびに組み立て直されます。質問の言葉ひとつで、速度の見積もりや「見た物」が変わりました。
MYTH / 思い込み誤った情報で記憶がゆがんだら、もう取り返しがつかない。
FACT / 研究では後から誤りがあったと警告すると、事後情報効果は平均して半分以下に減りました。ただし、ゼロにはなりません。
MYTH / 思い込みだまされやすい一部の人だけの話だ。
FACT / 研究ではゆがみやすさに個人差はありますが、記憶のゆがみは数百の研究で、多くの人に起きています。

04日常で生かせる視点

証言を聞くときは、内容だけでなく「どんな質問のあとで出てきた記憶か」に目を向けることが大切です。

  • 事件の報道で目撃者の話を見るときは、それが報道や周りの話を聞いた後の記憶かもしれない、と考えてみる。
  • 裁判員として証言を聞くときは、最初の供述と後の供述で何が変わったか、その間にどんな質問や情報があったかを確かめる。
  • 家族や友人に出来事を聞くときは「激突したの？」のような言葉を避け、「何があったの？」と開いた質問から始める。

05よくある質問

事後情報効果とは何ですか

出来事の後に誤った情報にふれることで、その出来事の記憶がゆがむ現象です。質問の言葉、人の話、報道などがきっかけになります。

質問の言葉でどのくらい記憶が変わりますか

1974年の実験では、「激突した」と聞かれた人の32%が、映像になかった割れたガラスを見たと答えました。「ぶつかった」と聞かれた人では14%でした。

ゆがんだ記憶を防ぐ方法はありますか

後から「誤った情報が混じっていた」と警告すると、影響は平均して半分以下に減ります。まず誘導しない質問をすることが基本です。
