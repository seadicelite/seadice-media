取り調べと冤罪

「空腹の裁判官は厳しくなる」は本当か。仮釈放の判断と食事休憩をめぐる研究と反論

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「判決は裁判官が朝食に何を食べたかで決まる」。そんな皮肉を確かめたとされる2011年の研究は、「空腹の裁判官」として世界中で紹介されました。では、本当に休憩の前後で判断が変わるのでしょうか。元の研究と、その後に出た反論を見ていきます。

SUMMARY

  1. イスラエルの仮釈放審理1,112件では、許可の割合が休憩直後の約65%から、次の休憩前にはほぼ0%まで下がり、休憩後に約65%へ戻った。
  2. 別の研究者は、弁護人のいない受刑者はたいてい各回の最後に回されると指摘し、追加の12日分（227件）では許可が15%（弁護人ありは35%）にとどまっていた。元の著者は、弁護人の有無を加えて分析し直しても結果は変わらないと反論している。
  3. 2016年のシミュレーション研究は、許可の審理ほど時間がかかるという事情だけで、同じくらいの大きさの「効果」が生まれうると示した。

01どんな心の仕組みが働いているのか

疲れると、人は手間のかかる判断を避けて「現状のまま」を選びやすいと考えられています。元の研究はこれで説明しようとしました。

元の研究の著者たちは、判断を重ねるほど頭が疲れ、裁判官が「却下」という無難な選択に流れると考えました。却下すれば受刑者は今のまま服役を続けるので、判断としては楽な方だからです。

一方で、こうした流れがデータに表れても、原因が「疲れ」や「空腹」とは限りません。審理の順番そのものが偶然でなければ、順番の偏りが同じ形のグラフを作ってしまうからです。

02研究でわかっていること

休憩の前後で許可率が大きく変わるデータはあります。ただ、その原因が空腹や疲れなのかは、反論が多く、確かめられていません。

約65%→ほぼ0%休憩直後から次の休憩前までの仮釈放許可率の変化（イスラエル、2011年の研究）
1,112件元の研究が分析した仮釈放審理の数（50日分、裁判官8人）
15%と35%弁護人なし・ありの受刑者の許可率（追加の227件、2011年の反論）

Danzigerら（2011）[1]

イスラエルの2つの仮釈放委員会で、経験豊富な裁判官8人による1,112件の判断を、10か月・50日分集めた。1日2回の食事休憩で区切ると、許可の割合は休憩直後の約65%から、次の休憩前にはほぼ0%まで少しずつ下がり、休憩後に約65%へ戻った。

対象: イスラエルの仮釈放審理 ／ 限界: 審理の順番が偶然かどうかを確かめきれていない。

Weinshall-MargelとShapard（2011）[2]

元のデータと追加の12日分（227件）を調べ、関係者にも聞き取りをした。委員会は同じ刑務所の案件を休憩前に終える方針で、弁護人のいない受刑者はたいてい最後に回されていた。弁護人がいない受刑者の許可は15%、いる受刑者は35%だった。著者らは、下がっていく流れは審理の順番で説明できると指摘した。これに対し元の著者らは同じ号で、弁護人の有無を加えて分析し直しても順番と休憩の影響は残ると反論している[4]。

対象: イスラエルの仮釈放審理 ／ 限界: 追加データには審理の順番の情報がない。

Glöckner（2016）[3]

コンピューターでのシミュレーションを行った。許可の審理は却下より時間がかかる。そのため、少し先を見て「長くなりそうな案件は休憩の後に回す」合理的な裁判官でも、同じくらいの大きさの「効果」が生まれうると示した。分析方法の細かな点が、この見かけの効果をさらに大きくしていたとも述べている。

対象: シミュレーション ／ 限界: 実際の裁判官の行動を直接調べたものではない。

03よくある思い込みと、研究が示す実際

「お腹がすくと判決が厳しくなる」は言いすぎです。データの形は確かでも、順番の偏りなど別の説明が残っています。

MYTH / 思い込み空腹の裁判官は判決が厳しくなることが証明された。
FACT / 研究では元の研究は休憩前後の変化を示しましたが、原因が空腹だとは確かめられていません。順番の偏りで説明できるという反論があります。
MYTH / 思い込み仮釈放は裁判官ひとりが決めている。
FACT / 研究では元の研究によれば、委員会は裁判官・犯罪学者・ソーシャルワーカーの3人で構成されていました。
MYTH / 思い込み有名な学術誌に載った結果なら、もう議論はない。
FACT / 研究では同じ学術誌に、同じ年のうちに反論が載りました。有名な研究ほど、その後の検証まで見ることが大切です。

04日常で生かせる視点

「同じ形のグラフでも、別の理由で説明できないか」と考える習慣が、研究や報道を読むときに役立ちます。

  • 「〇〇すると判断が変わる」という話を聞いたら、比べているグループに最初から違いがないかを考えてみる。
  • 裁判員として判断するときは、休憩の前後や疲れたときにこそ、証拠をもう一度見直す時間をとる。
  • 職場や家庭で大事なことを決めるときも、後回しにした案件ほど不利になっていないか、順番を意識してみる。

05よくある質問

「空腹の裁判官」の研究とは何ですか

2011年にイスラエルの仮釈放審理1,112件を調べた研究です。許可の割合が休憩直後の約65%から、次の休憩前にはほぼ0%まで下がり、休憩後に戻ることを示しました。

その結果に反論はありますか

あります。弁護人のいない受刑者が後半に回されやすいなど、審理の順番が偶然ではないという指摘や、許可の審理は時間がかかるという事情だけで同じ形が生まれうるというシミュレーション研究があります。元の著者は、弁護人の有無を加えても結果は変わらないと再反論しています。

結局、裁判官は空腹で判断を変えるのですか

わかっていません。休憩前後で許可率が変わるデータはありますが、空腹や疲れが原因だとは確かめられていません。
