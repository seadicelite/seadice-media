取り調べと冤罪

事件報道は裁判の判断に影響するのか。模擬陪審1万人超のメタ分析が示した「控えめだが確かな」偏り

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

大きな事件が起きると、裁判の前から容疑者についてたくさんの報道が流れます。裁判で判断する人は「報道ではなく、法廷の証拠だけで決める」ことが求められますが、本当にそれができるのでしょうか。模擬裁判の研究をまとめた結果を見ていきます。

SUMMARY

  1. 45の報告（参加者1万1,240人）をまとめた2022年のメタ分析では、被告に不利な報道は一人ひとりの有罪判断を増やし（r=.16）、評議後のグループの判断ではより大きかった（r=.35）。
  2. 同じメタ分析で、被告に有利な報道は有罪判断を減らした（r=-.21）。報道の向きによって、判断はどちらにも動いた。
  3. 320人の模擬陪審研究では、不利な報道を読んだグループはすべて、報道に触れないよう指示された後も評議で報道に言及していた。

01どんな心の仕組みが働いているのか

裁判の前に読んだ報道の内容が、法廷で見た証拠と記憶の中で混ざり、証拠の受け止め方を偏らせると考えられています。

報道の影響の仕組みとして、研究者は主に3つを挙げています。報道で作られた「事件の筋書き」に合わせて証拠を解釈すること、報道で読んだ情報を「法廷で聞いた」と思い込む記憶の取り違え、そして最初の印象に合うように後から入る証拠をゆがめて受け取ることです。

このメタ分析とは、たくさんの研究結果を統計的にまとめて全体の傾向を見る方法です。r（相関係数）は影響の強さを表す数字で、著者らは全体の影響を「控えめ」と表現しています。

02研究でわかっていること

報道は判断を「控えめに、しかし確かに」偏らせます。裁判官の注意や評議だけでは、偏りが消えにくいこともわかっています。

r=.16被告に不利な報道が一人ひとりの有罪判断に与えた影響（2022年のメタ分析）
r=.35被告に不利な報道が評議後のグループの判断に与えた影響（同）
1万1,240人メタ分析に含まれた参加者数（45の報告、77の効果量）

Hoetgerら（2022）[1]

1999年に行われた事件報道のメタ分析を更新した。45の報告・参加者1万1,240人の77の結果をまとめると、被告に不利な報道は一人ひとりの有罪判断を増やし（r=.16）、グループの判断ではさらに大きかった（r=.35）。有利な報道は有罪判断を減らした（r=-.21）。1本の記事に複数の事実が書かれているときや、報道から判断まで1週間未満のときに影響が強かった。

対象: 模擬陪審の実験 ／ 限界: 多くは模擬裁判で、実際の裁判とは状況が異なる。影響は出版された研究や学生の参加者で強めに出ていた。

Daftary-Kapurら（2014）[2]

実際の裁判を題材に、その地域で自然に報道に触れた住民115人と、実験で報道を読ませた156人を比べた。検察寄り・弁護寄りの報道を読んだ人は、それぞれ報道が有利にした側に沿った判断をしやすく、報道の量が多いほど偏りは大きかった。偏りは裁判の証拠を見た後も続いた。

対象: 米国の陪審員資格のある住民 ／ 限界: 1つの事件を題材にした研究。

RuvaとGuenther（2015）[3]

大学生320人に、裁判の1週間前に不利な報道か無関係な記事を読ませた。不利な報道を読んだ人は有罪に投票しやすく、記憶の誤りも多かった。評議の内容を分析すると、不利な報道を読んだグループはすべて、触れないよう指示された後も報道に言及し、ほかの人もそれをほとんど正さなかった。

対象: 米国の大学生 ／ 限界: 学生による模擬陪審で、録画された裁判を見た実験。

03よくある思い込みと、研究が示す実際

「プロや市民はきちんと証拠だけで判断できる」とは言い切れません。注意されても、評議しても、報道の影響は残ることがあります。

MYTH / 思い込み裁判で証拠を見れば、事前の報道の影響は消える。
FACT / 研究では報道の偏りは、裁判の証拠や主張を見た後も続いていました。
MYTH / 思い込みみんなで話し合えば、一人の偏りは打ち消される。
FACT / 研究では不利な報道を読んだグループはすべて、評議で報道に触れていました。グループの判断で影響が大きかった結果もあります。
MYTH / 思い込み実験室の結果は、現実の裁判には当てはまらない。
FACT / 研究では実際の地域で自然に報道に触れた住民と、実験で報道を読んだ人で、偏り方に大きな差はありませんでした。

04日常で生かせる視点

報道で知ったことと、確かめられた事実を分けて考えることが、裁判員としても日常でも役立ちます。

  • 事件の報道を読むときは、「警察の発表」「関係者の話」「確定した事実」を区別して受け取る。
  • 裁判員に選ばれたら、「これは法廷で出た証拠か、報道で知ったことか」と自分に問いかける。評議で報道の話が出たら、そっと指摘する。
  • 身近な人のうわさを聞いたときも、最初の印象に合う情報ばかり集めていないか振り返る。

05よくある質問

事件報道は裁判の判断に影響しますか

模擬裁判の研究をまとめた2022年のメタ分析では、被告に不利な報道は有罪判断を増やしていました（r=.16）。影響は控えめですが、確かに見られます。

被告に有利な報道でも影響はありますか

あります。有利な報道は有罪判断を減らしていました（r=-.21）。報道の向きによって、判断はどちらにも動きます。

裁判官が「報道は無視して」と伝えれば防げますか

十分とは言えません。触れないよう指示された後も、不利な報道を読んだ模擬陪審のグループはすべて評議で報道に言及していました。
