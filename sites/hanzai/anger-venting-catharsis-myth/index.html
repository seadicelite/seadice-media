パーソナリティと犯罪

怒りは「発散」すればおさまるのか。154研究のまとめが示した、殴るより落ち着くほうが効く理由

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「怒りはため込まずに吐き出したほうがいい」。クッションを叩く、大声を出すといった発散法は、よく勧められます。でも、発散は本当に怒りを小さくするのでしょうか。実験やメタ分析の結果は、この常識とは反対の方向を指しています。

SUMMARY

  1. 怒らされた人がサンドバッグを叩きながら相手のことを考えると、何もしない人より怒りが強く、攻撃的にもなった。
  2. 「攻撃的な行動は怒りを解消する」という文章を読んでからサンドバッグを叩いた人は、その後、より攻撃的にふるまった。
  3. 154の研究（10,189人）をまとめたメタ分析では、興奮を静める方法は怒りと攻撃を減らした（g = -0.63）が、興奮を高める方法には効果がなかった（g = -0.02）。

01どんな心の仕組みが働いているのか

怒りを発散すればすっきりする、という考えを「カタルシス説」と呼びます。しかし実験では、発散するとかえって怒りが続きやすくなりました。

カタルシスとは、心にたまったものを外に出して浄化するという考え方です。怒りを圧力鍋の蒸気のようにとらえ、抜けば楽になるとイメージします。

ところが、叩きながら相手のことを考えると、怒りの原因を何度も思い返すことになります。これを「反すう」と呼びます。反すうは怒りを冷ますどころか、燃料を足すように働くと考えられています。

02研究でわかっていること

発散は怒りを減らさず、むしろ強めることがありました。効果がはっきりしたのは、呼吸や瞑想など、体の興奮を静める方法です。

154怒りの対処法を調べた研究の数（メタ分析、2024年）
10,189人そのメタ分析に含まれた参加者の数
g = -0.63興奮を静める方法が怒りと攻撃を減らした効果の大きさ

Bushman（2002）[1]

怒らせた参加者に、サンドバッグを叩きながら相手のことを考えてもらうグループと、体を鍛えることを考えてもらうグループ、何もしないグループを比べた。相手のことを考えながら叩いた人は最も怒りが強く、相手に大きな音を浴びせる攻撃も最も多かった。何もしないほうが、発散より効果的だった。

対象: 実験参加者 ／ 限界: 実験室での短時間の測定で、日常の怒りとは場面が異なる。

Bushmanら（1999）[2]

「攻撃的な行動は怒りを解消するよい方法だ」という文章を読んだ人は、反対の内容を読んだ人より、サンドバッグを叩きたがった。さらに、その文章を読んでから実際に叩いた人は、その後の課題でより攻撃的だった。発散を信じることが、攻撃を後押しする形になった。

対象: 実験参加者 ／ 限界: 実験室での攻撃の測定で、現実の暴力とは異なる。

Kjærvik・Bushman（2024）[3]

怒りの対処法を調べた154の研究（184の独立した集団、10,189人）をまとめた。深呼吸、マインドフルネス、瞑想など興奮を静める方法は、怒りと攻撃を減らした（g = -0.63）。叩く、走るなど興奮を高める方法は、全体として効果がなかった（g = -0.02）。静める方法は、犯罪をした人を含むさまざまな人で効いていた。

対象: 154の研究 ／ 限界: 興奮を高める方法の結果はばらつきが大きく、一律には言えない。

03よくある思い込みと、研究が示す実際

「怒りはため込むより発散」は誤解です。発散で怒りが燃え続けることがあり、静めるほうが効果的でした。

MYTH / 思い込み怒りはクッションやサンドバッグを叩いて発散するとおさまる。
FACT / 研究では叩きながら相手を思い浮かべると、怒りも攻撃もかえって強くなりました。何もしないほうがましでした。
MYTH / 思い込み運動をすれば怒りは消える。
FACT / 研究では走るなど体を興奮させる活動は、全体として怒りや攻撃を減らしていませんでした。運動の健康効果とは別の話です。
MYTH / 思い込み怒りを静めるのは、我慢して押し込めることだ。
FACT / 研究では効果があったのは、呼吸や瞑想などで体の興奮を下げる方法です。怒りの気持ちを否定することとは違います。

04日常で生かせる視点

怒りを感じたら、「発散する」より「熱を下げる」ことを意識すると、言動を選び直す余裕が生まれます。

  • 事件の報道で「怒りを発散させていた」とあっても、発散が怒りを解消するとは限らないと知っておく。
  • 裁判員として判断するとき、「カッとなった」という説明だけでなく、怒りが続いた経過にも目を向ける。
  • 家族や同僚とぶつかったら、言い返す前にゆっくり呼吸し、少し時間をおいてから話す。

05よくある質問

カタルシス効果とは何ですか

心にたまった怒りなどを外に出すと、すっきりして気持ちが軽くなるという考え方です。怒りについては、実験で支持されていません。

怒ったときにサンドバッグを叩くのは逆効果ですか

2002年の実験では、相手のことを考えながら叩いた人は、何もしない人より怒りも攻撃も強くなりました。

怒りを静めるのに効果がある方法は何ですか

154の研究のまとめでは、深呼吸、マインドフルネス、瞑想など、体の興奮を静める方法が怒りと攻撃を減らしていました。
