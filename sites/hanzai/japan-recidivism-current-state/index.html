刑罰と更生

「再犯者率46%」は再犯が増えている証拠なのか。犯罪白書の数字の読み方と、出所者の再入率の実際

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「検挙された人の半分近くが再犯者」という数字を聞くと、再犯が増えているように感じます。ところが、この数字は読み方に注意が必要です。日本の公式統計である犯罪白書の最新版から、再犯の現状を確かめます。

SUMMARY

  1. 令和7年版犯罪白書によると、2024年の刑法犯検挙人員に占める再犯者の割合（再犯者率）は46.2%。再犯者の数は8万8,697人で、ピークの2006年（14万9,164人）から大きく減っている。
  2. 2023年の出所受刑者の2年以内再入率は13.8%で、1999年の23.4%から低下傾向にある。ただし2023年は前年より0.8ポイント上がった。
  3. 2015年の出所受刑者の10年以内再入率は、満期釈放者53.7%、仮釈放者36.7%だった。再入所した人の多くは5年以内に戻っていた。

01どんな心の仕組みが働いているのか

再犯の数字が「多い」と感じられやすいのは、割合の数字だけが伝えられ、分母の変化が見落とされやすいからです。

再犯者率は「検挙された人のうち、前にも検挙歴がある人の割合」です。初めて罪を犯す人が減ると、再犯者の数が減っていても、割合は上がって見えます。

一方、出所した人のうち何人が刑務所に戻ったかを見るのが再入率です。どちらの数字も、何を分母にしているかを確かめることで、意味が正しく読み取れます。

02研究でわかっていること

再犯者の数も出所者の再入率も、長い目で見ると下がっています。それでも出所者の3人に1人は5年以内に刑務所に戻っており、課題は残っています。

46.2%刑法犯検挙人員に占める再犯者の割合（2024年）
13.8%出所受刑者の2年以内再入率（2023年出所者）
34.0%出所受刑者の5年以内再入率（2020年出所者）

法務省（2025）a[1]

刑法犯で検挙された再犯者の数は2006年の14万9,164人をピークに減り、2024年は8万8,697人だった。再犯者率は、初犯者がそれ以上のペースで減ったため1997年以降上昇したが、2021年から4年連続で下がり、2024年は46.2%だった。再犯者と初犯者の数は、2023年から2年続けて増えた。

対象: 刑法犯で検挙された人 ／ 限界: 検挙された人に限られ、見つかっていない犯罪は含まない。

法務省（2025）b[2]

出所受刑者の2年以内再入率は1999年の23.4%から下がり、2023年出所者は13.8%だった。2020年出所者の5年以内再入率は34.0%。2015年出所者の10年以内再入率は満期釈放者53.7%、仮釈放者36.7%で、刑務所に入った回数が多いほど再入率は高かった。

対象: 刑事施設を出所した人 ／ 限界: 再び受刑した場合のみを数え、罰金などは含まない。

Sampsonら（2003）[3]

非行歴のある少年たちを7歳から70歳まで追った、最も長い部類の追跡研究。どの犯罪グループでも、遅かれ早かれ年齢とともに犯罪は減っていた。子どもの頃の危険因子や家庭環境からは、生涯の犯罪の経過はうまく予測できなかった。

対象: 非行歴のある少年（男性） ／ 限界: 男性のみで、女性や現代の若者に当てはまるかは不明。

03よくある思い込みと、研究が示す実際

「再犯者率が高い＝再犯が増えている」は誤解です。数は減っていますが、出所者の再入所は今も多く、両方を見ることが大切です。

MYTH / 思い込み再犯者率46%は、再犯がどんどん増えている証拠だ。
FACT / 研究では再犯者の数はピークの約6割まで減っています。割合が高く見えるのは、初犯者がもっと減ったためです。
MYTH / 思い込み一度罪を犯した人は、ずっと犯罪を続ける。
FACT / 研究では7歳から70歳までの追跡研究では、どのグループでも年齢とともに犯罪は減っていました。
MYTH / 思い込み出所した人の多くは、すぐ刑務所に戻る。
FACT / 研究では2年以内に戻る人は13.8%です。ただし10年で見ると、満期釈放者の半数以上が再入所していました。

04日常で生かせる視点

再犯の数字を見るときは、「割合か数か」「何を分母にしているか」を確かめるだけで、印象が大きく変わります。

  • ニュースで再犯者率を見たら、再犯者の数と初犯者の数の変化も一緒に確かめる。
  • 裁判員として再犯の可能性を考えるときは、年齢とともに犯罪が減る傾向があることも思い出す。
  • 「あの人はまたやる」と決めつけそうなときは、多くの人が時間とともに犯罪から離れているという事実を思い出す。

05よくある質問

再犯者率とは何ですか

刑法犯で検挙された人のうち、以前にも検挙されたことがある人の割合です。2024年は46.2%でした。

日本の再犯は増えていますか

再犯者の数は2006年のピークから減っています。ただし2023年から2年続けて、再犯者・初犯者ともに増えています。

出所した人はどのくらい刑務所に戻りますか

2023年出所者の2年以内再入率は13.8%、2020年出所者の5年以内再入率は34.0%でした。
