Case file

なぜ人は罪を犯すのか

暮らしが豊かになったのに、なぜ犯罪は増えたのか。日常の行動パターンから犯罪を説明するルーティン・アクティビティ理論

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「景気が良くなり、貧しい人が減れば、犯罪も減るはずだ」。多くの人がそう考えます。ところが1960年代の米国では、暮らしが良くなる一方で犯罪が大きく増えました。この矛盾を、罪を犯す人の性質ではなく、人々の日常の行動パターンから説明しようとしたのがルーティン・アクティビティ理論です。

SUMMARY

  1. 米国では1960〜75年に、強盗が263%、加重暴行が164%、殺人が188%増えた。同じ時期、都市の貧困層は1,130万人から830万人に減っていた。
  2. 同じ時期、朝8時に誰もいない世帯の割合は1960〜71年でほぼ1.5倍になり、住宅への昼間の空き巣が侵入盗全体に占める割合は1960年の16%から1975年の33%に増えた。
  3. コロナ禍の外出制限を調べた23か国27都市の分析では、犯罪は平均37%減った。強盗は46%、盗みは47%減り、殺人は14%減だった。

01どんな心の仕組みが働いているのか

犯罪が起きるには「罪を犯そうとする人」「狙われやすい対象」「守る人の不在」の3つが、同じ時と場所にそろう必要がある、というのがこの理論の中心です。

1979年に米国の社会学者コーエンとフェルソンが提案しました。それまでの犯罪学は、主に「なぜその人は罪を犯すのか」を問うていました。この理論は見方を変え、犯罪が起きる「状況」に注目しました。

たとえば共働きや一人暮らしが増えると、昼間に誰もいない家が増えます。持ち運びやすい家電が増えれば、盗まれやすい物も増えます。罪を犯す人の数が変わらなくても、3つがそろう機会が増えれば犯罪は増える、と考えたのです。

02研究でわかっていること

日常の行動の変化が犯罪の量を左右することは、歴史データとコロナ禍の「自然の実験」の両方で確かめられています。

263%米国の強盗の増加率（1960〜75年）
16%→33%侵入盗に占める住宅への昼間の空き巣の割合（米国、1960年→1975年）
37%外出制限後に減った都市の犯罪（23か国27都市の平均、2020年）

Cohenら（1979）[1]

米国の1947〜74年の犯罪の推移を、人々の日常の行動の変化から説明した。家の外で過ごす活動が増えるほど犯罪の機会が増えると考え、女性の就労や一人暮らしの世帯の増加などをもとに指標を作った。予想どおり、住宅への昼間の空き巣が侵入盗に占める割合は1960年の16%から1975年の33%に増えた。

対象: 米国の全国統計 ／ 限界: 国全体の時系列データで、個々の犯罪の状況を直接見たものではない。

Prattら（2005）[2]

地域の特徴と犯罪の関係を調べた200以上の研究をメタ分析でまとめ、どの犯罪理論がどれだけ支持されるかを比べた。ルーティン・アクティビティ理論は「中程度の支持」だった。貧困や家族の崩れなどが重なる地域の不利の指標は、最も強く安定した予測因子の一つだった。

対象: 地域単位の研究 ／ 限界: 理論の検証に使われた指標が研究ごとに異なる。

Nivetteら（2021）[3]

コロナ禍の外出制限を、日常の行動が急に変わった「自然の実験」として分析した。23か国27都市で、犯罪は平均37%減った。強盗や盗みのように街で人と出会う犯罪ほど大きく減り、制限が厳しい都市ほど減り方が大きかった。一方、侵入盗は都市によって84%減から38%増まで幅があった。

対象: 23か国27都市の警察の記録 ／ 限界: 都市は欧州と南北アメリカに偏り、警察の記録には届け出られない犯罪の問題がある。

03よくある思い込みと、研究が示す実際

犯罪の増減は「悪い人が増えたか」だけでは決まりません。人の動き方が変われば、同じ社会でも犯罪の量は大きく変わります。

MYTH / 思い込み暮らしが良くなれば、犯罪は必ず減る。
FACT / 研究では1960〜75年の米国では、貧困層が減る中で強盗が263%増えました。豊かさが外出や持ち物を増やし、機会を広げた面があります。
MYTH / 思い込み犯罪が増えたのは、悪い人が増えたからだ。
FACT / 研究ではこの理論は、罪を犯そうとする人の数が同じでも、3つの条件がそろう機会が増えれば犯罪は増えると説明します。
MYTH / 思い込み外出制限で、あらゆる犯罪が減った。
FACT / 研究では強盗や盗みは大きく減りましたが、殺人の減少は14%にとどまり、侵入盗は増えた都市もありました。

04日常で生かせる視点

犯罪のニュースを「人」の話としてだけでなく、「状況」の話としても読むと、見え方が広がります。

  • 犯罪が増えた、減ったという報道を見たら、その時期に人々の暮らし方がどう変わったかも考えてみる。
  • 裁判員として事件の経緯を聞くときは、本人の性格だけでなく、その時と場所でどんな条件が重なったかにも目を向ける。
  • 被害にあった身近な人を「不注意だった」と責めず、犯罪は複数の条件が重なって起きるものだと受け止める。

05よくある質問

ルーティン・アクティビティ理論とは何ですか

罪を犯そうとする人、狙われやすい対象、守る人の不在の3つが、同じ時と場所にそろうと犯罪が起きるという考え方です。1979年に提案されました。

この理論は、罪を犯す人の動機を説明しますか

いいえ。この理論は動機より、犯罪が起きる状況や機会に注目します。なぜ罪を犯そうとするのかは、別の理論が扱います。

わかっていないことは何ですか

3つの条件をどう測るかは研究ごとに違い、理論の支持は「中程度」とまとめられています。コロナ禍の研究も、警察に届け出られない犯罪を数えられないという限界があります。
