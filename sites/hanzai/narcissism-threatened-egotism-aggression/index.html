自己愛が強い人は攻撃的なのか。「傷つけられた自己愛」の実験と、437研究が示した「挑発されたとき」の関係

約7分で読めます 出典照合済み（2026-11-05）

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

「人を傷つけるのは、自信がない人だ」。長くそう考えられてきました。これに対し1990年代、自分を高く見る人がその評価を否定されたときこそ攻撃が起きる、という説が出されます。「傷つけられた自己愛」の説です。437研究・約12万人をまとめた2021年のメタ分析では、自己愛と攻撃の関連は r = .26 でした。関連は、挑発されたときにはっきり強まっていました。

SUMMARY

  1. 1998年の実験では、自己評価の高さは攻撃と関係しなかった。自己愛が強い人がけなされたときに、けなした相手へ強く攻撃した。
  2. 437研究のメタ分析（2021年）では、自己愛と攻撃の相関は r = .26。挑発ありでは r = .29、挑発なしでは r = .12 だった。
  3. 「自信のなさ」と攻撃の関連を示す研究もあり、論争は続いている。実験室での攻撃の測り方にも、計算方法がばらばらという問題がある。

01 どんな心の仕組みが働いているのか「傷つけられた自己愛」とはどういうこと？

自分を高く評価している人が、その評価を誰かに否定されたとき、怒りを外に向ける。これが「傷つけられた自己愛（脅かされた自己像）」の説です。

1996年、心理学者のバウマイスターらは、攻撃・犯罪・暴力についての研究を分野を越えて見直しました。そして「自己評価が低い人ほど暴力的になる」という通説は、証拠と合わないと結論づけました。

代わりに示したのが、次の考え方です。自分はすぐれているという見方を、誰かや何かの出来事が否定する。すると人は、自分の評価を下げる代わりに、怒りを相手に向ける。とくに、ふくらんだ自己像や、不安定な自己像ほど、否定にぶつかりやすいとされました。

ここでいう自己愛は、病気の診断名ではありません。「自分は特別だ」「ほめられて当然だ」と感じやすい、ふつうの人にもある性格の傾向として測られています。似た性格の研究は「ダークトライアドとは何か」でも取り上げています。

02 研究でわかっていること自己愛と攻撃は、どのくらい関係する？

関連は確かにあり、とくに挑発されたときに強まります。437研究のメタ分析では自己愛と攻撃の相関は r = .26、挑発ありでは r = .29、挑発なしでは r = .12 でした。

相関係数（r）は −1 から 1 の値をとり、0 は関連なしを表します。r = .26 は、はっきりあるが強くはない、という程度の関連です。

Bushman・Baumeister（1998）[2]

2つの実験で、参加者の自己評価と自己愛の強さを測りました。そのあと、自分をけなした相手、ほめた相手、関係のない第三者のいずれかを攻撃できる場面をつくりました。自己評価の高さは攻撃と関係しませんでした。自己愛の強さとけなされる経験が重なると、けなした相手への攻撃がとくに強くなりました。関係のない人への八つ当たりは全体に少なく、自己愛とも自己評価とも関係しませんでした。

対象: 2つの実験の参加者（実験室研究） ／ 限界: 攻撃は実験室の中の行動で測られており、現実の暴力そのものではありません。

Bushman ら（2009）[3]

「自己評価の低さが攻撃を生む」という説が現場の研究で再び注目されたことを受け、前の実験データを分析し直し、新しい実験と現場での研究を加えました。新しい実験では、相手に不快な騒音を浴びせる量で攻撃を測りました。自己愛が強い人は、侮辱や屈辱で挑発されたときだけ、しかも批判した相手に対してだけ、攻撃的になりました。自己評価が高く、自己愛も強い組み合わせで攻撃が最も強くなりました。

対象: 実験室での実験と、相手への否定的な評価で間接的な攻撃を測った現場研究 ／ 限界: 傷つけられた自己愛の説を提唱したグループ自身による検証です。

Donnellan ら（2005）[4]

一方、3つの研究で、自己評価の低さと攻撃・反社会的行動・非行の間に一貫した関連を見つけた研究もあります。関連は、本人・教師・親のどの評価でも、米国とニュージーランドのどちらでも、10代でも大学生でも見られました。親の支えや学力、家庭の経済状況、知能などを統制しても残り、自己愛の強さとは別に表れていました。

対象: 米国とニュージーランドの10代と大学生（3研究） ／ 限界: 調査にもとづく研究で、実験のように原因を確かめたものではありません。

Kjærvik・Bushman（2021）[5]

437の研究・12万3,043人をまとめたメタ分析です。自己愛は攻撃（r = .26）とも暴力（r = .23）とも関連しました。関連は挑発のある条件（r = .29）で、挑発のない条件（r = .12）より強く出ました。ただし挑発がなくても関連は有意でした。男女、年齢、学生かどうか、個人主義の国か集団主義の国かを問わず関連が見られ、出版バイアス（目立つ結果ほど論文になりやすい偏り）を考えても結果は崩れなかったと報告されています。

対象: 実験・横断調査・追跡調査を含む437研究 ／ 限界: 調査研究も多く含まれ、全体として因果を示すものではありません。著者の1人は1998年の実験の著者でもあります。

Elson ら（2014）[7]

こうした実験でよく使われるのが、反応の速さを競い、負けた相手に騒音を浴びせる課題です。この課題では、攻撃の得点の計算方法が少なくとも13通り使われてきました。3つの研究のデータで計算方法を比べると、どの方法を選ぶかで、統計的に意味があるかどうかも効果の大きさも大きく変わりました。

対象: この課題を使った3つの研究のデータ ／ 限界: 自己愛の研究そのものを見直したものではなく、測り方の問題を示した研究です。

03 よくある思い込みと、研究が示す実際攻撃的な人は「自信がない人」なのか？

自信の高い低いだけでは説明できません。攻撃と結びつきやすいのは、自己愛の強さと、自分の評価を否定される経験の組み合わせです。ただし自己評価の低さの関連を示す研究もあります。

MYTH / 思い込み人を攻撃するのは、自分に自信がない人だ。
FACT / 研究では1998年の実験では、自己評価の高さは攻撃と関係しませんでした。2009年の研究では、自己評価が高く自己愛も強い人が、挑発されたときに最も攻撃的でした。一方で、自己評価の低さと非行の関連を示した研究もあり、どちらか一方だけで説明はできません。
MYTH / 思い込み自己愛が強い人は、いつでも誰にでも攻撃的だ。
FACT / 研究では関連は挑発があるときに強く（r = .29）、ないときは弱い（r = .12）ものでした。1998年の実験では、攻撃は自分をけなした相手に向かい、関係のない人への八つ当たりは少なめでした。
MYTH / 思い込み問題なのは、自信満々で目立ちたがりのタイプだけだ。
FACT / 研究では2021年のメタ分析では、誇大型だけでなく、他人の評価に過敏な「傷つきやすい」自己愛や、特別扱いを当然と考える特権意識も、攻撃と関連していました。

恥をかかされたときの怒りは、子どもでも確かめられています。10代前半の子どもを対象にした2011年の研究では、恥ずかしい出来事は子どもを怒らせ、その傾向は自己愛の強い子どもほど強く表れました[6]。あいまいな出来事を悪意と読む癖については「敵意帰属バイアス」の記事で、やり返したい気持ちについては「人はなぜ仕返しをしたくなるのか」で扱っています。

04 日常で生かせる視点この研究から、ニュースや人間関係をどう見ればいい？

攻撃を性格だけで説明せず、「どんな場面で、何を否定されたときか」に目を向けることです。関連は平均の傾向であり、個人を決めつける根拠にはなりません。

  • 「自己中心的な人だから」で片づけない。研究で関連が強まったのは、挑発やけなされる経験と重なったときでした。性格と場面の組み合わせで見るほうが、研究の結果に沿っています。
  • 相関 .26 の意味を思い出す。関連はあっても強くはありません。平均の傾向なので、性格の傾向だけで人を危険視する根拠にはなりません。
  • 「実験でわかった」の中身を見る。この分野の攻撃は、多くが実験室の騒音課題などで測られています。測り方で結果が変わりうるという指摘も、あわせて知っておくと結果を冷静に読めます。

05よくある質問

自己愛が強い人は、犯罪や暴力をしやすいのですか？

2021年のメタ分析では、自己愛と暴力の相関は r = .23 でした。関連はありますが、強い関連ではなく、相関なので「自己愛が暴力を生む」とまでは言えません。特定の人を性格だけで危険と決めつける根拠にはなりません。

自己肯定感が高いのは悪いことなのですか？

悪いとは言えません。1998年の実験では、自己評価の高さそのものは攻撃と関係しませんでした。攻撃が強まったのは、自己愛の強さと、けなされる経験が重なったときです。一方で、自己評価の低さと非行の関連を示した研究もあり、自己評価の高低だけで攻撃を説明するのは難しいというのが現状です。

「傷つきやすい自己愛」の人も攻撃的になるのですか？

2021年のメタ分析では、自信過剰に見える「誇大型」だけでなく、他人の評価に過敏な「過敏型（傷つきやすい自己愛）」や、特別扱いを当然と考える「特権意識」も、攻撃と関連していました。ふつうの性格の範囲の自己愛と、病的な水準の自己愛のどちらにも関連が見られました。
