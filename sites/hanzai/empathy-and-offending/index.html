パーソナリティと犯罪

「共感できない人が罪を犯す」は本当か。106の効果量をまとめると、共感と攻撃の関係は思ったより弱かった

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

ニュースで加害者が「人の痛みがわからない人」と語られることがあります。共感力の低さが犯罪を生む、という考えはとても自然に感じられます。では研究では、共感と犯罪はどのくらい強く結びついているのでしょうか。

SUMMARY

  1. 犯罪をした人とそうでない人を比べた38の研究のメタ分析では、他人の気持ちを理解する力（認知的共感）に、はっきりした差があった。
  2. 成人の共感と攻撃の関係を106の効果量でまとめたメタ分析では、相関はr = -0.11と弱く、身体的な攻撃ではr = -0.12だった。
  3. 英国の中学生720人の調査では、暴力をふるったと答えた生徒は、男女ともそうでない生徒より共感が低かった。

01どんな心の仕組みが働いているのか

共感には、相手の気持ちを頭で理解する「認知的共感」と、相手の気持ちを自分も感じる「情動的共感」の2つがあると考えられています。

共感が低いと、相手の苦しみが行動のブレーキになりにくい。この考えから、共感を育てることは、多くの加害者向けプログラムの柱になってきました。

ただし、犯罪には生活環境や衝動の強さなど、多くの要因が関わります。共感がどの程度ブレーキとして働いているのかは、データで確かめる必要があります。

02研究でわかっていること

共感の低さと犯罪・攻撃には関係がありますが、その強さは小さめです。差がはっきりしたのは、気持ちを理解する認知的共感でした。

van Langenら（2014）[1]

犯罪をした人とそうでない人の共感を比べた38の研究をまとめた。他人の気持ちを理解する認知的共感には、はっきりした一貫した差があった。相手の気持ちを感じる情動的共感の差は、分析の方法によっては見られなかった。女性を含む研究では、差が小さくなっていた。

対象: 38の研究 ／ 限界: 共感は質問紙で測られており、実際の行動とは異なる場合がある。

Vachonら（2014）[2]

成人の共感と攻撃の関係を、地域住民、学生、犯罪をした人の研究から106の効果量でまとめた。相関はr = -0.11と弱かった。言葉の攻撃でr = -0.20、身体的な攻撃でr = -0.12、性的な攻撃でr = -0.09と、種類が違ってもおおむね同じ傾向だった。

対象: 成人の研究（106の効果量） ／ 限界: 共感の測り方が少数の質問紙にかたよっている。

Jolliffe・Farrington（2007）[3]

英国の中学生720人（平均14.8歳）に、匿名で共感と非行を答えてもらった。何らかの非行をした男子は共感が低かったが、女子では差がなかった。暴力をふるった生徒は、男女ともそうでない生徒より共感が低かった。

対象: 英国の中学生720人 ／ 限界: 一時点の調査で、どちらが原因かはわからない。

03よくある思い込みと、研究が示す実際

「共感がない人が犯罪をする」は単純すぎます。関係はあるものの弱く、共感以外の要因も大きいのです。

MYTH / 思い込み犯罪をする人は、みな他人の痛みを感じない。
FACT / 研究では差がはっきりしたのは、気持ちを頭で理解する認知的共感でした。相手の気持ちを感じる力の差は、研究によってはっきりしませんでした。
MYTH / 思い込み共感が低いことが、攻撃の主な原因だ。
FACT / 研究では成人のメタ分析では、共感と攻撃の相関はr = -0.11でした。攻撃の違いのごく一部しか説明しません。
MYTH / 思い込み共感の低さと犯罪の関係は、男女で同じだ。
FACT / 研究では中学生の調査では、非行全体で見ると男子でのみ共感が低く、女子では差がありませんでした。

04日常で生かせる視点

「あの人には人の心がない」と片付けず、共感以外の要因にも目を向けると、人の行動を理解しやすくなります。

  • 報道で加害者が「共感力がない」と語られても、それだけで行動を説明できるとは限らないと考える。
  • 裁判員として判断するとき、性格のレッテルより、その人の状況や経緯を示す証拠を重視する。
  • 身近な人とすれ違ったときは、相手の気持ちを「理解する」ことと「感じる」ことを分けて考えてみる。

05よくある質問

認知的共感と情動的共感の違いは何ですか

認知的共感は相手の気持ちを頭で理解する力、情動的共感は相手の気持ちを自分も感じる力です。犯罪との関係では、認知的共感の差のほうがはっきりしていました。

共感が低いと犯罪をしやすいのですか

関係はありますが弱いものです。成人の106の効果量をまとめた研究では、共感と攻撃の相関はr = -0.11でした。

共感と犯罪の関係はなぜ弱いのですか

犯罪には、環境や衝動の強さなど多くの要因が関わるためと考えられます。また、共感の測り方が質問紙にかたよっているという課題も指摘されています。
