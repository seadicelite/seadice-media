取り調べと冤罪

「疑わしい」と思うと証拠の見え方が変わるのか。指紋やDNAの専門家でも起きる確証バイアス

約3分で読めます

AI RESEARCH公開された研究と公的統計をAIが調べて整理しました。実在の事件を興味本位で扱わず、犯罪の手口の詳細は書きません（出典は末尾）。

容疑者が自白したと聞いたあとで指紋を見ると、一致しているように見えてしまう。そんなことは専門家にも起きるのでしょうか。「科学的な鑑定は客観的だ」という思い込みを、研究で確かめてみます。

SUMMARY

  1. 同じ指紋を、以前に「一致」と判断した同じ専門家に、「一致しない」と思わせる文脈で見せると、多くの専門家が以前と違う判断をした。
  2. 実際の事件のDNA混合資料を、事件の情報なしで17人の専門家に解釈してもらうと、結果はばらばらだった。過半数は、検査機関の公判前の結論と異なっていた。
  3. 確証バイアスの研究をまとめた論文は、自白などの情報が、一般の目撃者の知覚や記憶、専門家の判断をゆがめうると指摘した。

01どんな心の仕組みが働いているのか

人は一度「この人が怪しい」と思うと、それに合う情報を探し、合う方向に解釈しがちです。これを確証バイアスと呼びます。

確証バイアスは、注意不足や悪意から起きるものではありません。最初の情報が、その後の見方の枠組みになるという、誰にでもある心の働きです。

指紋やDNAの鑑定にも、人が見て判断する部分があります。そこに「容疑者が自白した」などの事件の情報が入ると、判断が引っぱられることがあります。

02研究でわかっていること

専門家の鑑定でも、事件の情報や周りの見立てで結論が変わることが、実験で示されています。

17人事件の情報なしでDNA混合資料を解釈した専門家（2011年）
過半数そのうち検査機関の公判前の結論と異なる判断をした専門家

Drorら（2006）[1]

指紋の専門家が以前に「一致」と判断した指紋を、同じ専門家にもう一度見せた。今度は「一致しない」と思わせる事件の文脈を添えた。すると、多くの専門家が以前の自分の判断と違う結論を出した。専門家も、指紋の特徴そのもの以外の情報に影響されることを示した。

対象: 指紋の専門家 ／ 限界: 実験の場面で、ふだんの仕事とは条件が異なる。

Dror・Hampikian（2011）[2]

判決の出た実際の事件のDNA混合資料（複数の人のDNAが混ざったもの）を、北米の17人のDNA鑑定の専門家に解釈してもらった。事件の情報は伝えなかった。解釈は専門家の間で一致しなかった。また過半数は、事件の情報を知っていた検査機関の公判前の結論とは違う判断だった。

対象: 北米のDNA鑑定の専門家17人 ／ 限界: 一つの事件の資料のみ。

Kassinら（2013）[3]

指紋の誤った一致判定が問題となったマドリードの爆破事件や、2009年の米国科学アカデミーの批判をもとに、法科学の確証バイアスを整理した論文。最初の印象や期待が人の知覚や判断をゆがめるという古典的な研究を紹介した。自白などの情報が、一般の目撃者や専門家の判断をゆがめうるとし、検査機関での偏りや、その法廷への影響を減らす方法を提案した。

対象: 研究のまとめ ／ 限界: 新しいデータを集めた研究ではない。

03よくある思い込みと、研究が示す実際

「科学的な鑑定なら人の思い込みは入らない」は誤りです。人が判断する部分があるかぎり、文脈の影響を受けます。

MYTH / 思い込み鑑定は機械的なので、思い込みが入る余地はない。
FACT / 研究では指紋もDNA混合資料も、最後は人が見て判断します。17人の専門家の解釈は一致しませんでした。
MYTH / 思い込み経験を積んだ専門家なら、事件の情報に左右されない。
FACT / 研究では以前に自分で「一致」とした指紋でも、別の文脈を添えると、多くの専門家が判断を変えました。
MYTH / 思い込み自白と鑑定が両方そろえば、証拠は独立して確かめ合っている。
FACT / 研究では自白を知っていると、鑑定の見え方が変わることがあります。その場合、二つは独立した証拠ではありません。

04日常で生かせる視点

証拠を見る前に何を知っていたか。それが判断を左右すると意識するだけで、決めつけを減らせます。

  • ニュースで「鑑定で一致」と聞いたら、鑑定者が事件の情報を知っていたかどうかに注目する。
  • 裁判員になったら、自白と鑑定が本当に別々に得られた証拠なのかを確かめる。
  • 日常で「やっぱりあの人だ」と感じたら、反対の証拠を一つ探してみる。

05よくある質問

確証バイアスとは何ですか

自分の考えや最初の印象に合う情報を探し、合うように解釈してしまう傾向です。誰にでも起きる心の働きです。

DNA鑑定でも間違いは起きるのですか

複数の人のDNAが混ざった資料では、人の解釈が必要です。17人の専門家に同じ資料を見せた研究では、解釈が一致しませんでした。

どうすれば鑑定の偏りを減らせますか

研究者は、検査機関での偏りを減らす方法を提案しています。ただ、どの方法がどれだけ効くかは、ここで紹介した研究ではまだ確かめられていません。
