輸入通関の流れと関税・消費税の計算

このレッスンの学習目標

  • 輸入（納税）申告から輸入許可までの流れを、申告納税方式と結びつけて説明できる
  • 関税の課税価格が、輸入港までの運賃・保険料を含む価格（CIF価格）を基準にすることがわかる
  • 関税と消費税・地方消費税を、計算の順番どおりに求められる

要点

  1. 輸入（納税）申告とは、輸入する貨物の品名・数量・価格と、納める税額を税関に申告する手続のことです。
  2. 一般の貨物の関税は申告納税方式で、輸入者が自分で税額を計算して申告します。
  3. 関税の課税価格は、実際に支払う価格に輸入港までの運賃・保険料などを加えた価格で、いわゆるCIF価格が基準です。
  4. 消費税・地方消費税は、課税価格に関税額と酒税などの個別の消費税額を足した額にかかります。
  5. 税関は審査・検査を行い、原則として税金の納付を確かめてから輸入を許可します。担保を出せば、許可前の引取りや納期限の延長を使える場合があります。

01輸入（納税）申告と申告納税方式

一般の貨物を輸入するときは、輸入者が品名・数量・課税標準・税額を自分で申告します。これを申告納税方式といい、輸入申告と納税申告を1つの書類で行います。

輸入通関の全体像はレッスン1-4で見ました。ここでは、税金の面から手続を細かく見ていきます。税関の説明では、一般の貨物は、品名、数量、課税標準、税額などを輸入者自らが申告します。

このやり方を申告納税方式といいます。税額は、原則として納税義務者の申告で決まります。申告がない場合や、計算が法律に合っていない場合などに限り、税関長の処分で決まります。

申告は輸入（納税）申告書で行います。インボイス、包装明細書、B/Lなどの運送書類、運賃明細書、保険料明細書なども必要です。品目の番号であるHSコードと税率の調べ方は、レッスン10-3で学びます。

02課税価格は「CIF価格」が基準

関税の課税価格は、輸入者が実際に支払う価格に、輸入港までの運賃・保険料などを加えた価格です。インコタームズでいうCIF価格に当たります。

関税のかけ方には、価格を基準にする従価税と、数量を基準にする従量税があります。従価税の基準になる価格を課税価格といいます。

関税定率法第4条によると、課税価格は、買手が実際に支払う価格（現実支払価格）が出発点です。そこに含まれていなければ、輸入港までの運賃、保険料、仲介手数料、容器や包装の費用などを加えます。

そのため、FOB条件で買った場合でも、海上運賃と保険料を足して課税価格を計算します。外国通貨の価格は、税関長が毎週公示する為替相場で円に換算します。

03関税と消費税の計算の手順（例）

関税額は「課税価格 × 関税率」で求めます。消費税は「課税価格 + 関税額」に7.8％、地方消費税はその消費税額の22/78で、合計すると10％になります。

消費税法第28条により、輸入品の消費税は、課税価格に関税額と、酒税などの個別の消費税額を足した額にかかります。標準税率は消費税7.8％と地方消費税2.2％、食品などの軽減税率は6.24％と1.76％です。

例として、課税価格50万円、関税率10％の貨物で計算します。関税額は50万円×10％で5万円です。消費税の基準は55万円なので、消費税は55万円×7.8％で42,900円です。

地方消費税は42,900円×22/78で12,100円です。消費税と合わせると55,000円で、55万円のちょうど10％です。納める税は、関税と合わせて合計105,000円になります。実際の計算では端数を処理します。課税価格や消費税の基準は1,000円未満、関税や消費税の額は100円未満を切り捨てます。

04審査・検査、納付、そして輸入許可

税関は書類を審査し、必要なら貨物を検査します。そのうえで、原則として関税・消費税・地方消費税が納められたことを確かめてから、輸入を許可します。

税関検査では、申告の内容と現品が同じかを確かめます。麻薬などの輸入できない物がないか、他法令の許可を受けているか、納税申告が正しいかなども見ます。

税金は、銀行の窓口のほか、NACCSを使う場合は口座からの引き落とし（ダイレクト方式）でも納められます。関税法第72条により、原則として納付が済まなければ輸入は許可されません。

05許可前の引取りと、納期限の延長

急ぎの貨物は、担保を出して税関長の承認を受ければ、許可前に引き取れます（BP）。担保を出して納期限を延ばす制度や、承認を受けた輸入者向けの特例もあります。

輸入許可前引取り（BP：Before Permit）は、原産地証明書の提出が遅れるときなどに使えます。関税等に相当する担保を出し、税関長の承認を受けます。輸入できない貨物や、他法令の許可がない貨物には使えません。

納期限延長制度は、担保を出すと納付を待ってもらえる制度です。個別延長方式では、輸入許可日の翌日から3か月以内に延ばせます。特例輸入者は、輸入申告と納税申告を分けて先に貨物を引き取れます。この制度はレッスン10-5で学びます。

KEYWORDSキーワード（日本語・英語）

このレッスンで覚えておきたい用語です。貿易の書類や契約は英語が中心なので、英語名も一緒に覚えましょう。

輸入（納税）申告Import (tax) declaration

輸入する貨物の内容と納める税額を、あわせて税関に申告する手続。

申告納税方式Self-assessment system

納める税額を、原則として納税義務者自身の申告によって確定させる方式。

課税価格Customs value

関税を計算する基準となる価格。現実支払価格に輸入港までの運賃・保険料などを加えて求める。

従価税・従量税Ad valorem duty / Specific duty

価格を基準にかける関税が従価税、数量を基準にかける関税が従量税。

地方消費税Local consumption tax

消費税とあわせて納める税。輸入では消費税額の22/78に当たる額。

輸入許可前引取り（BP）Before Permit

担保を出して税関長の承認を受け、輸入許可の前に貨物を引き取る制度。

納期限延長制度Deferred payment system

担保を出すことで、関税や消費税などの納付期限を延ばしてもらえる制度。

答えを見る

正解: 2. 実際に支払う価格に、輸入港までの運賃・保険料などを加えた価格（CIF価格）を基準にする
関税定率法第4条により、現実支払価格に、輸入港までの運賃・保険料などの加算要素を加えた価格が課税価格です。いわゆるCIF価格に当たります。

Q2. 課税価格100万円、関税率5％の貨物（標準税率の対象）を輸入するとします。消費税（7.8％）の計算の基準になる額はいくらですか。端数処理は考えないものとします。

答えを見る

正解: 1. 105万円
関税額は100万円×5％で5万円です。消費税の基準は課税価格に関税額を足した105万円で、消費税は105万円×7.8％で81,900円になります。

Q3. 輸入許可前引取り（BP）について、正しいものはどれですか。

答えを見る

正解: 3. 関税等に相当する担保を出し、税関長の承認を受ければ、輸入許可の前に引き取れる
BPは、関税等に相当する担保を出し、税関長の承認を受けて使う制度です。輸入してはならない貨物や、他法令の許可・承認を受けていない貨物には使えません。
