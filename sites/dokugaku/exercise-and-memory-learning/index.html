運動すると記憶や勉強の成果は良くなるのか。運動と学習の研究

約5分で読めます

AIによる調査公開された研究をAIが調べて整理しました（独自の実験ではありません。出典は末尾）。

「運動すると頭が良くなる」と聞いて、勉強の前に走るべきか迷ったことはありませんか。結論から言うと、1回の軽い運動は記憶を少し助けるという研究が多くあります。ただし効果は大きくなく、運動しながら覚えるのは逆効果という結果もあります。運動は勉強の代わりではなく、勉強の「前後」に置く補助です。

3行でわかる

  1. 1回の有酸素運動のあとは、記憶テストの成績が少し良くなる。29件の研究をまとめた分析で確認されている。
  2. タイミングが大事。覚えた直後〜4時間以内の運動はプラス、運動しながら覚えるのは小さなマイナスだった。
  3. 何か月も続ける運動の効果は「小さい」。運動だけで成績が上がるわけではなく、思い出す練習などの勉強法が主役。

01「運動で頭が良くなる」は、どこまで本当か

本当なのは「1回の運動のあと、覚えたことが少し残りやすくなる」という部分です。運動を習慣にすれば勉強の成果が大きく上がる、とまでは言えません。

運動と記憶の研究は、大きく2種類に分かれます。

  • 1回の運動（20分ほど自転車をこぐなど）の直後に、単語を覚えたり思い出したりする実験。
  • 長く続ける運動（週3回を数か月〜1年など）のあとで、記憶や考える力を測る実験。

この2つは結果がかなり違います。「運動はいい」と一言でまとめると、違いが見えなくなります。

02科学的にわかっていること

1回の運動には記憶を助ける効果があり、特に「長く残る記憶」で目立ちます。長く続ける運動の効果は小さく、記憶への効果ははっきりしません。

Roigら（2013）[1]

運動と記憶の研究をまとめたメタ分析。1回の運動は、長く残る記憶に対して効果量 0.52（著者らの表現で「中〜大」）。一方、長く続ける運動の長期記憶への効果は 0.07 で、はっきりした差は出なかった。

対象: 1回の運動の研究29件、長く続ける運動の研究21件 ／ 限界: 実験ごとに運動の強さや記憶テストの種類がばらばらで、まとめた数字は目安にとどまる。

短い時間だけ覚えておく記憶（すぐ思い出すテスト）では、1回の運動の効果は 0.26、長く続ける運動は 0.15 でした[1]。どちらもプラスですが、大きな差ではありません。

Loprinziら（2019）[2]

25本の論文をまとめ、「いつ運動するか」で効果を比べたメタ分析。覚えたあと4時間以内の運動は d = 0.47 のプラス。運動しながら覚えたときは d = −0.12 で、わずかにマイナスだった。

対象: 主に20歳前後の大学生 ／ 限界: 覚えて4時間以上あとの運動（d = 1.05）は、2本の研究・3つの結果だけで、まだ当てにできない。覚える前の運動は d = 0.11 で、はっきりした差とは言えなかった。

この研究の数字を、タイミング別に並べました。

運動のタイミング効果量 d読み方
覚える前0.11ごく小さい（はっきりしない）
覚えながら−0.12わずかにマイナス
覚えた直後〜4時間以内0.47中くらいのプラス
覚えて4時間以上あと1.05研究が2本だけで未確定

数字はLoprinziら（2019）のメタ分析より[2]。研究の数が少ない行ほど、今後の研究で変わる可能性があります。

Ludygaら（2020）[3]

健康な人を対象にした80件のランダム化比較試験をまとめたメタ分析。長く続ける運動の、考える力全体への効果は「小さい」だった。体の動きの協調が必要な運動（コーディネーション運動）で効果がやや大きかった。

対象: 健康な人 ／ 限界: 記憶だけでなく、注意や判断なども含めた「考える力」全体の結果。女性では効果が小さめだった。

Ericksonら（2011）[4]

55〜80歳の120人を、週3回40分のウォーキング群と、ストレッチ群に分けて1年間続けた。ウォーキング群は、記憶に関わる脳の部分（海馬）の体積が約2%増え、ストレッチ群は約1.4%減った。

対象: アメリカの高齢者 ／ 限界: 記憶テストの成績は両方のグループで上がり、グループ間の差は確認されなかった。

この結果は有名ですが、その後14件の研究（737人）をまとめたFirthら（2018）では、運動による海馬全体の体積の増加ははっきりせず、左側だけで効果が見られました[5]。「運動で脳が大きくなる」と言い切るのは早いと考えられます。

また、多くの実験は大学生が単語リストを覚える短い課題です。仕事のあとに資格の勉強をする社会人で、同じ大きさの効果が出るとは限りません。

03今日からできる小さな一歩

運動は「覚えたあと」に置きます。勉強しながらの運動は避け、軽く息が上がる程度の運動を15〜20分から試します。

1

覚える勉強のあとに、20分歩く

単語や用語を覚えたら、その日のうちに（できれば4時間以内に）早歩きや軽いジョギングをします。少し息が上がる程度で十分です。

所要 15〜20分

2

歩きながら暗記カードをめくらない

運動しながら新しく覚えると、わずかに成績が下がるという結果があります。運動中は、すでに覚えたことを頭の中で思い出す程度にします。

所要 0分

3

翌日、見ずに思い出してみる

運動の効果は小さいので、主役は勉強法です。前日の内容を見ずに書き出し、言えなかった所だけ見直します。やり方は思い出す練習の記事で紹介しています。

所要 5分

持病がある人や体調に不安がある人は、無理のない範囲で行ってください。この記事は運動の指導や医療の助言ではありません。

04続けるためのコツ

運動を「勉強の締めくくり」として決まった順番に組み込むと、どちらも続けやすくなります。成果を運動だけに期待しすぎないことも大切です。

  • 「暗記15分 → 散歩20分」を1セットにして、毎日同じ順番で行う。
  • 通勤や買い物の歩きを、勉強のあとの時間帯に寄せる。
  • 雨の日は室内で階段の上り下りなど、代わりの運動を先に決めておく。
  • 夜遅くの激しい運動で睡眠を削らない。学んだあとの睡眠も記憶を助けます（睡眠と記憶の記事）。

歩くことと気分の研究は、姉妹メディアの記事「散歩すると気分は軽くなる？」で紹介しています。勉強で疲れた日の気分転換にも使えます。

05よくある質問

勉強の前と後、運動するならどっち？

研究では「後」の方が効果がはっきりしています。Loprinziら（2019）のメタ分析では、覚えたあと4時間以内の運動は d = 0.47 のプラスでした。覚える前の運動は d = 0.11 で、はっきりした差は出ていません。

運動しながら勉強すると効率がいいの？

新しく覚えるときは、おすすめしにくいです。同じメタ分析では、運動しながら覚えた場合の効果は d = −0.12 で、わずかにマイナスでした。運動中は、すでに覚えたことの確認にとどめるのが無難です。

運動を習慣にすると、記憶力は上がるの？

効果はあっても小さいと考えられます。Roigら（2013）では、長く続ける運動の長期記憶への効果ははっきりしませんでした。80件の試験をまとめたLudygaら（2020）でも、考える力への効果は「小さい」という結果でした。
