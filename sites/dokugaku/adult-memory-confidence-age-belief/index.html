「年のせいで覚えられない」と落ち込んだら？学び直しで自信をなくしたときの立て直し方（年齢の思い込みと記憶の研究）

約7分で読めます

AIによる調査公開された研究をAIが調べて整理しました（独自の実験ではありません。出典は末尾）。

昨日覚えた用語が出てこない。若い同僚はすぐ覚えるのに、自分は何度見ても残らない。学び直しの途中で「やっぱり年のせいだ」と自信をなくす人は少なくありません。研究では、「もの忘れが増えた」という実感は実際の記憶とあまり一致せず、年齢の決めつけを意識すること自体が成績を下げうることがわかっています。落ち込みを実感ではなく記録で確かめ直せば、立て直せます。

3行でわかる

  1. 高齢者を対象にした53件の研究のメタ分析では、「自分の記憶をどう感じているか」と記憶テストの成績の相関は r = .062 と小さかった。実感は当てにならない。
  2. 平均69.5歳の3,882人を含むメタ分析では、年齢の決めつけを意識させると成績が下がった（d = .28）。ただし公表された研究に偏っており、実際の効果はもっと小さい可能性がある。
  3. 立て直しは、思い出せた数を記録する、勉強の前に年齢の話を持ち込まない、目の前の課題で小さく見通しを立てる、の3つから。

01 悩みの正体「年のせいで覚えられない」は本当？

半分は本当で、半分は思い込みです。年齢とともに落ちやすい記憶の働きはありますが、「覚えが悪くなった」という実感は、実際の記憶よりも気分や思い込みに左右されやすいことがわかっています。

新しいことを素早く覚える力は、年齢とともにゆっくり落ちやすいことが知られています。ここは否定しません。年齢と学ぶ力の全体像は、大人の学び直しは不利なのかの記事にまとめています。

問題は、そこから先です。1つ思い出せないたびに「年のせいだ」と考えると、落ち込みが勉強の量を減らし、量が減ると本当に覚えられなくなります。この記事は、その悪循環から抜けるための手順を中心に書きます。

02 科学的にわかっていること年齢の思い込みは記憶にどう影響する？

年齢の決めつけを意識させると、高齢者の記憶テストの成績は下がる傾向があります。また、「覚えが悪い」という実感は、記憶テストの成績より、気分の落ち込みと強く結びついていました。

Lamontら（2015）[1]

年齢の決めつけ（「年をとると記憶が落ちる」という見方）を意識させると成績が下がるか、32本の論文の82の効果量（3,882人、平均69.5歳）をまとめたメタ分析。全体の効果は d = .28（小〜中程度）。決めつけを意識させる方法では d = .52 だった一方、「記憶は年齢とともに落ちる」という事実の説明として伝えた場合は d = .09 で、はっきりした影響は見られなかった。記憶の課題では d = .21、ほかの頭を使う課題では d = .68。

対象: 平均69.5歳の高齢者の実験室の課題 ／ 限界: 公表された研究では d = .42 だったが、未公表の研究では d = −.03 で、効果のある結果ほど公表されやすい偏りがあった。北米の研究では効果がはっきりしなかった。

Armstrongら（2017）[2]

同じテーマで、高齢者の記憶に絞ったメタ分析。出来事や内容を覚える記憶（エピソード記憶）で d = 0.373、頭の中で一時的に情報を保つ記憶（作業記憶）で d = 0.253 の低下が見られた。ただしエピソード記憶では、何も見ずに思い出すテストでは差が出た一方、選択肢から選ぶテストや手がかりつきのテストでは差が出なかった。直後のテストでは差が出たが、時間をおいたテストでは差が出なかった。

対象: 23本の論文（公表19本・未公表4本） ／ 限界: 研究の場での実験。この記事では論文の要旨で内容を確認した。

Crumleyら（2014）[3] ／ Schweizerら（2018）[4]

高齢者を対象にした53件の研究のメタ分析では、「自分の記憶をどう感じているか」と記憶テストの成績の相関は r = .062 と、0より大きいものの小さかった。英国の地域から集めた2,544人の研究では、気分の落ち込みの症状が多い人ほど「もの忘れがある」と答えやすかったが、言葉の記憶テストの成績とは結びつかなかった（年齢・性別・全般的な認知能力・不安の影響を除いても同じ）。

対象: 高齢者の研究53件 ／ 英国の地域から集めた幅広い年齢の大人 ／ 限界: どちらも原因と結果を確かめた実験ではない。Schweizerらはもの忘れを「はい・いいえ」の1問で聞いている。Crumleyらは要旨で確認した。

BeaudoinとDesrichard（2011）[5] ／ Westら（2008）[6]

健康な大人を対象にした107件の研究（673の効果量）のメタ分析では、記憶への自信と記憶の成績の相関は r = .15 と小さいが、はっきりあった。結びつきは「ふだんの記憶力」への自信より、「この課題でどれくらいできそうか」という目の前の見通しの方が強かった。高齢者向けの記憶講座の研究では、何歳でも記憶は伸ばせると伝え、自分で目標を決め、できた経験を重ねる講座で、順番待ちのグループより記憶への自信と、名前や話の記憶が良くなった。

対象: 健康な大人の研究107件 ／ 高齢者の講座の参加者 ／ 限界: メタ分析は相関で、自信が成績を上げるとまでは言えない。講座は記憶の工夫の練習も含んでおり、どの部分が効いたかは分けられない。どちらも要旨で確認した。

注意したいのは、これらの研究の多くが60代後半以降の高齢者を対象にしていることです。30〜50代の学び直しで同じことが起きるかは、直接は確かめられていません。下の手順は、わかっていることを大人の独学に当てはめたものです。

03 今日からできる小さな一歩覚えられないと落ち込んだら、どう立て直す？

実感ではなく「思い出せた数」の記録で確かめ、勉強の前に年齢の話を持ち込まず、目の前の課題で小さく見通しを立てます。翌日の結果で判断し、気分の落ち込みが強いときは先に休みます。

1

「覚えられない」を、思い出せた数で確かめる

今日覚えた10個を、翌日に何も見ずに書き出し、思い出せた数をノートに書きます。これを1週間続けます。記憶をどう感じているかと実際の成績の相関は r = .062 と小さく[3]、実感だけで「落ちた」と決めると外れやすいからです。

所要 1日5分 × 1週間

2

勉強の前に、年齢の話を持ち込まない

「どうせ年だから」と口にする、年齢と記憶の記事を読むなどは、勉強が終わってからにします。メタ分析では、決めつけを否定するより、そもそも意識させない方が、少なくとも同じくらい影響を小さくしていました[1]。

所要 0分（順番を変えるだけ）

3

直後の出来ではなく、翌日の結果で判断する

年齢の決めつけの影響は、直後に何も見ずに思い出すテストで出やすく、時間をおいたテストや選択肢から選ぶテストでは出ていませんでした[2]。覚えた直後に1つ出てこなくても、判断は翌日の記録まで待つ、というのがこの記事からの提案です。

所要 判断を1日待つ

4

「記憶力」ではなく「今日の10問」で見通しを立てる

勉強を始める前に「この10問のうち、明日7問思い出す」のように、目の前の課題で数字を決めます。結果と比べて、当たったかを記録します。記憶への自信は、ふだんの記憶力より目の前の課題への見通しの方が、成績と結びついていました[5]。自分で目標を決め、できた経験を重ねる講座では、記憶への自信と成績が良くなっています[6]。

所要 1回1分

5

気分の落ち込みが続くときは、先に休む

もの忘れの訴えは、記憶テストの成績より気分の落ち込みと強く結びついていました[4]。眠れない、何をしても楽しくない日が続くなら、勉強量を減らして休むことを優先します。つらさが続くときは、こころの健康相談統一ダイヤル（0570-064-556）などに相談してください。

所要 —

落ち込んだときに浮かびやすい考えと、確かめ方を表にしました。研究をもとに、この記事で独学向けに当てはめたものです。

浮かびやすい考え研究からわかること確かめ方
最近、覚えが悪くなった実感と記憶テストの相関は小さい[3]翌日に思い出せた数を1週間記録する
年だから、もう無理だ決めつけを意識すると成績が下がりうる[1][2]勉強の前にその話をしない
さっき覚えたのに、もう出てこない影響は直後のテストで出やすかった[2]翌日の結果で判断する
もの忘ればかりで、気分が沈むもの忘れの訴えは気分の落ち込みと結びついていた[4]量を減らして休む。続くなら相談する

04 続けるためのコツ取り戻した自信を、また失わないためには？

記録を続け、落ち込んだら記録を見返します。思い出せなかった日があっても、1週間の数字で判断します。覚え方そのものを見直すのも効果的です。

  • 思い出せた数の記録は、1日単位ではなく1週間単位で見る。調子の悪い日は誰にでもある。
  • 何も見ずに思い出す練習は、年齢を問わず効く覚え方です。大人向けの具体的なやり方は、大人の学び直しの勉強のやり方の記事にまとめています。
  • 忘れていた所の覚え直しは、忘れた後の覚え直しの記事が参考になります。
  • うまくいかなかった自分を責めてしまうときは、自分への思いやりの記事も読んでみてください。

ここで紹介した決めつけの研究は、多くが高齢者を対象にした実験室の課題で、効果も小さめです。公表された研究に偏っているため、実際の影響はさらに小さい可能性があります。それでも、思い込みと実感のずれを記録で確かめることは、年齢を問わず損のない方法です。

05よくある質問

「最近覚えが悪い」と感じるのは、記憶が落ちている証拠ですか？

そうとは限りません。高齢者を対象にした53件の研究のメタ分析では、「自分の記憶をどう感じているか」と記憶テストの成績の相関は r = .062 と小さいものでした。英国の2,544人の研究では、もの忘れの訴えは気分の落ち込みと強く結びついていた一方、言葉の記憶テストの成績とは結びついていませんでした。実感ではなく、思い出せた数の記録で確かめるのが確実です。

「年をとると記憶が落ちる」と考えると、本当に成績が下がるのですか？

実験ではその傾向が見られます。平均69.5歳の3,882人を含む研究のメタ分析では、年齢の決めつけを意識させると成績が下がり、効果の大きさは d = .28 でした。ただし、公表された研究だけで効果が大きく、未公表の研究では見られなかったため、実際の効果はこれより小さい可能性があります。

自信を取り戻すには、何から始めればいいですか？

「記憶力全体」ではなく「今日の10問のうち何問思い出せそうか」のように、目の前の課題で小さく見通しを立て、結果を記録することから始めます。107件の研究のメタ分析では、記憶への自信と成績の結びつきは、記憶全般への自信より、目の前の課題への見通しの方が強くなっていました。
