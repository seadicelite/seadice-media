このレッスンの学習目標

  • 非注意による見落としとは何かを、具体例とともに説明できる
  • 注意の負荷が高いほど、予期しない出来事への気づきが減ることを説明できる
  • 見落としやすさが、能力の個人差よりも状況の要因に左右されることを説明できる

要点

  1. 非注意による見落とし（インアテンショナル・ブラインドネス）とは、注意を他のことに向けている間、視野に入っているはずの出来事に気づけなくなる現象のことです。
  2. 大学構内で行われた実験では、何かを数える課題の負荷が高いほど、近くで起きた予期しない出来事に気づく人の割合が下がりました。
  3. 気づきやすさは、ワーキングメモリなどの個人の能力差ではなく、課題や出来事が起きた場所と注意を向けている場所との距離に、大きく左右されることが分かっています。

01非注意による見落としとは何か

非注意による見落としとは、注意を他のことに向けている間、視野に入っているはずの物事に気づけなくなる現象のことです。

前のレッスンまでで見てきたように、知覚とは、感覚器官から届いた信号を、脳が注意や経験にもとづいて組み立てる働きでした。この「注意」の向け方しだいで、はっきり見えているはずの物事にすら気づけなくなることがあります。これを非注意による見落とし（インアテンショナル・ブラインドネス）と呼びます。

この現象は、視力や感覚器官の異常によるものではありません。目には光の情報が届いていても、注意という限られた資源が別の課題に使われていると、脳がその情報を意味のあるものとして組み立てる段階まで処理が進まないために起こると考えられています。

次のセクションからは、この現象を実験で測った2つの研究を見ていきます。1つは、注意を向ける場所からの距離が気づきやすさに与える影響を調べた研究、もう1つは、現実に近い状況で、課題の負荷が気づきやすさに与える影響を調べた研究です。

02注意を向けている場所から離れているほど、気づきにくい

2015年の実験では、予期しない対象が注視点から離れているほど、また課題が難しいほど、気づく人の割合が下がりました。

心理学者クライツらは2015年、学術誌PLoS ONEに発表した実験で、参加者に図形の判断課題をさせながら、ときどき画面の決まった位置に予期しない灰色の図形を出現させ、気づいたかどうかを報告させました。

静止した図形を使った課題では、予期しない図形が注視点から2度の位置に出たときは46.7%の参加者が気づきましたが、7度の位置に出たときに気づいた参加者は28.6%でした。線が動く別の課題でも、注視点に近い位置では65.6%、離れた位置では36.6%が気づくという、同じ傾向が確認されました。

研究チームはさらに、参加者のワーキングメモリの容量や、注意を広く配れるかどうかを測る別の課題の成績との関連を調べましたが、静止課題の近い条件で弱い関連が見られた以外、見落としを安定して予測するものはありませんでした。気づきやすさは、個人の能力差よりも、注意を向けている場所と出来事が起きた場所との距離に左右されていたのです。

03課題の負荷が高いほど、予期しない出来事に気づきにくい

大学構内で行われた実験では、数える課題の負荷が高い条件で気づいた人の割合は42%、負荷が低い条件では72%でした。

1995年、アメリカのボストンで、逃げる容疑者を追っていた警察官が、別の警察官による暴行の近くを走り抜けたのに、暴行を見ていないと証言し、偽証罪に問われる事件がありました。心理学者チャブリスらは2011年、学術誌i-Perceptionに発表した実験で、この状況を大学構内で再現しました。

参加者は、街灯で照らされたコースを走る協力者を追いかけ、その協力者の頭に触れた回数を数えました。コースの途中では、別の3人の協力者が喧嘩を演じ、参加者はそれに近づくまで少なくとも15秒間、喧嘩を見ることができました。

負荷を操作した実験では、左右の手による頭タッチを別々に数えるという難しい課題を課された33人のうち、喧嘩に気づいたのは42%でした。一方、数えずに走者を追うだけでよかった25人のうち、気づいたのは72%で、この差は統計的にも意味のある差でした。研究チームは、この結果から、件の警察官が「見ていない」と述べたことは、偽証ではなく真実だった可能性があると述べています。

04日常生活でどう役立つか

非注意による見落としは誰にでも起こりうるため、見落としが許されない場面では、注意を1つの課題に集中させる工夫が役に立ちます。

これらの実験が示すのは、見落としやすさが「注意力が足りない人」の特別な問題ではなく、注意という資源が限られている以上、誰にでも起こりうる仕組みだということです。目撃証言のように、ある出来事を見ていたはずの人が、別の作業に注意を向けていたために重要な部分を見落とすことは、十分にありえます。

この仕組みを踏まえると、運転中のスマートフォン操作のように、見落としが事故につながりうる場面では、複数の作業に注意を分けること自体にリスクがあると考えられます。注意力の個人差を鍛えるよりも、そもそも注意を分けなくてよい状況を作ることが、見落としを減らす現実的な工夫になります。

非注意による見落とし（インアテンショナル・ブラインドネス）Inattentional blindness

非注意による見落としとは、注意を他のことに向けている間、視野に入っているはずの物事に気づけなくなる現象のことです。

注意の負荷Attentional load

注意の負荷とは、ある課題を行うために、どれだけの注意の資源が使われているかの程度のことです。

ワーキングメモリWorking memory

ワーキングメモリとは、情報を短い時間保持しながら、同時に処理するための心の働きのことです。
