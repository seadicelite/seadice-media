  • MBTIが、ビッグファイブとどのように異なる枠組みで性格を捉えているか説明できる

要点

  1. MBTIとは、性格を4つの指標それぞれで2つの型に分け、16種類の「タイプ」に分類する性格診断のことです。
  2. 2023年の研究では、MBTIの指標は、リーダーシップに関わる行動のばらつきのうち、わずか約1%しか説明できませんでした。
  3. 血液型性格判断についても、2015年の研究では、7つの性格特性のうち血液型と統計的に関連したのは1つだけで、その効果もきわめて小さいものでした。

01MBTIとは何か。ビッグファイブとの違い

MBTIとは、性格を4つの指標それぞれで2つの型に分け、外向型か内向型かなど、16種類の「タイプ」に人を分類する性格診断のことです。

MBTIとは、Myers-Briggs Type Indicatorの略で、外向(E)か内向(I)か、感覚(S)か直観(N)か、思考(T)か感情(F)か、判断(J)か知覚(P)か、という4つの指標それぞれについて、どちらの型にあてはまるかを判定し、「ENFP」のような4文字の組み合わせで、16種類のタイプに人を分類する性格診断です。

このレッスンの前半(第11章の第2レッスン)で学んだビッグファイブは、神経症傾向や外向性などの特性を、連続的な強さの違い(次元)として捉える考え方でした。これに対してMBTIは、連続的な強さの違いを2つの型に分け、どちらか一方に人をあてはめる点で、考え方の枠組みが異なります。

この違いが、実際にMBTIの測定結果にどのような影響を与えているのかを、研究データから見ていきます。

02MBTIは実際の行動をどれくらい予測できるか

2023年に発表された研究では、MBTIの指標は、リーダーシップに関わる行動のばらつきのうち、わずか約1%しか説明できませんでした。

2023年に学術誌Frontiers in Psychologyに発表された、サラテ=トーレス(Zarate-Torres)とコレア(Correa)の論文は、コロンビアの大学で経営学を学ぶ464人の学生を対象に、MBTIの4つの指標と、リーダーシップに関わる行動との関係を、確認的因子分析と構造方程式モデリングで調べています。

同じ論文によると、MBTIの指標とリーダーシップ行動との関係は「弱い」もので、説明できる割合(決定係数R2)は0.01、つまり約1%にすぎませんでした。外向性は「ビジョンを示す」「心に働きかける」という行動とわずかに関連し、直観の指標は「変化に挑む」「ビジョンを示す」という行動とわずかに関連していましたが、いずれも小さな関連でした。

約1%という割合は、MBTIのタイプを知っても、その人が実際にどのようにリーダーシップを発揮するかは、ほとんど予測できないことを意味します。

03血液型性格判断とは何か。科学的な根拠は

2015年の研究では、7つの性格特性のうち血液型(ABO)と統計的に関連したのは1つだけで、その効果もきわめて小さいものでした。

日本では、ABO式の血液型(A・B・O・AB型)によって性格が決まるという「血液型性格判断」が広く知られています。この考え方を検証した研究の1つが、2015年に学術誌PLoS ONEに発表された、ツチミネ(Tsuchimine)らの論文です。

同じ論文では、精神的な疾患のない1427人の日本人(男性849人、女性578人、平均年齢28.2歳)を対象に、気質と性格を測る質問紙(TCI、7つの特性を測定)への回答と、血液型(遺伝子型と、A・B・O・AB型という表現型の両方)との関連を分析しています。

分析の結果、7つの特性全体を見た分析(MANCOVA)では、遺伝子型(p=0.001)・表現型(p=0.014)のいずれでも統計的に意味のある差が見られましたが、特性ごとに見ると、統計的に意味のある差が見られたのは「持続性」という1つの特性だけで、しかもその効果の大きさ(偏イータ2乗)は、遺伝子型で0.010、表現型で0.006と、きわめて小さいものでした。これは、血液型が性格のばらつきのうち1%にも満たない部分しか説明しないことを意味します。

04科学的に支持されない性格診断に共通すること

MBTIと血液型性格判断には、実際の行動や性格との関連を示す効果が、きわめて小さいという共通点があります。

ツチミネらの論文自身も、「血液型の遺伝子型と持続性という特性との関連は、比較的弱いものである可能性があり、慎重に解釈すべきである」と述べ、この結果を予備的なものと位置づけています。

MBTI(決定係数約1%)と血液型性格判断(効果の大きさ1%未満)は、どちらも、実際の行動や性格との関連を示す効果がきわめて小さいという共通点があります。これは、このレッスンの前半で見たビッグファイブの質問紙(NEO-PI-Rの内的一貫性.79〜.85、自己・他者評定の一致.34〜.62)と比べても、心理学的な根拠の薄さを示しています。

多くの人に当てはまりそうに感じられることや、広く知られていることは、科学的な根拠があることとは別の問題です。性格診断を利用するときは、娯楽として楽しむのか、研究にもとづく判断の材料にするのかを区別することが大切です。

KEYWORDSキーワード（日本語・英語）

このレッスンで覚えておきたい用語です。英語名も一緒に覚えると、海外の教科書や論文が読みやすくなります。

MBTI（マイヤーズ・ブリッグス・タイプ指標）Myers-Briggs Type Indicator

MBTIとは、性格を4つの指標それぞれで2つの型に分け、16種類の「タイプ」に人を分類する性格診断のことです。

血液型性格判断Blood type personality theory

血液型性格判断とは、ABO式の血液型によって性格が決まるという、日本で広く知られている考え方のことです。

予測的妥当性Predictive validity

予測的妥当性とは、ある測定方法の結果が、将来の行動や成果をどれくらい正しく予測できるかを示す、妥当性の1つのことです。

効果量（効果サイズ）Effect size

効果量(効果サイズ)とは、2つの変数の間の関連や差の大きさを、サンプルの人数に左右されない数値で示す指標のことです。
