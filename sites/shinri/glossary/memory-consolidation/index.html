記憶の定着とは

英語: Memory Consolidation ・ 更新日 2026-10-04

記憶の定着とは、新しく覚えた情報が、時間の経過とともに安定した記憶として保持されるようになっていく過程のことです。特に睡眠が、この過程を助けることが数多くの研究で示されています。

01記憶の定着をくわしく

記憶の定着を説明する考え方の一つに「能動的システム固定化モデル」があります。これは、学習した直後の記憶が一度海馬に蓄えられ、その後、脳の広い領域である大脳皮質とやり取りを重ねることで、長期的な記憶として移し替えられていく、という考え方です。

2021年のレジェス-レシナ(Reyes-Resina)らのレビューによると、ノンレム睡眠の間には、大脳皮質の緩やかな電気的な波(徐波)、脳の中心部に起こる紡錘波、海馬で起こる鋭い波(リップル)という複数の脳活動が重なって起こり、学習時に活動した神経細胞の集まりが、短くまとまった形で再び活動する「リプレイ」という現象が起きることがわかっています。

2025年のグッテセン(Guttesen)らのレビューでは、深いノンレム睡眠(徐波睡眠)を長く取った人ほど、学習前のペアの記憶の成績が良かったという研究結果が紹介されています。一方、睡眠不足の状態で新しいことを学習すると、海馬の働きが弱まり、思い出す力にも悪い影響が出ることが示されています。

ただし、記憶の定着は睡眠だけで決まるものではなく、学習のしかたや、その後の復習なども関わる複雑な過程です。「寝れば覚えたことが自動的に完璧に定着する」といった単純な理解は、研究結果を超えた言い方になります。

02身近な例

試験前日に新しい単語を覚えたとき、徹夜するよりも睡眠を取ったほうが翌日に思い出しやすいのは、記憶の定着に睡眠が関わっているためと考えられます。

FAQよくある質問

記憶の定着とは何ですか？

記憶の定着とは、新しく覚えた情報が、時間とともに安定した記憶として保持されるようになっていく過程のことです。睡眠がこの過程を助けることが研究で示されています。

記憶の定着と記憶の符号化の違いは？

符号化は情報を記憶として取り込む最初の段階を指しますが、定着はその後、時間をかけて記憶を安定させていく段階を指します。

寝るだけで記憶は完璧に定着しますか？

いいえ。睡眠は記憶の定着を助けることが示されていますが、学習のしかたや復習なども関わる複雑な過程であり、睡眠だけで決まるわけではありません。
