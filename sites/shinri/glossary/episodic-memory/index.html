エピソード記憶とは

英語: Episodic Memory ・ 更新日 2026-10-04

エピソード記憶とは、特定の時と場所で起きた個人的な出来事を、そのときの文脈とともに覚えている記憶のことです。

01エピソード記憶をくわしく

エピソード記憶という言葉は、心理学者タルヴィングが提唱した概念です。2024年にハールとマコーマックが発表した総説によると、タルヴィングはエピソード記憶を「時間的に日付けられた出来事についての情報を受け取り、保存するしくみ」と位置づけ、何が・どこで・いつ起きたかという情報を扱う点を重視しました。

エピソード記憶は、世界についての一般的な知識を扱う意味記憶とは区別されます。2009年にサデンドルフらが発表した論文では、ヘルペス脳炎によって海馬を含む脳の部位が損傷を受けた患者クライヴ・ウェアリングの事例が紹介されています。彼はエピソード記憶を深刻に損なわれた一方で、言葉の意味など意味記憶の多くは保たれていました。

この事例が示すように、海馬は意識的なエピソード記憶の想起に重要な役割を果たすと考えられています。神経画像を用いた研究では、将来の出来事を具体的に想像しようとするときにも海馬の活動が高まることが報告されており、海馬が過去の記憶だけでなく、未来を思い描く働きにも関わっている可能性が示されています。

エピソード記憶は、単に出来事の情報を保持しているだけの記憶ではありません。自分がその出来事を経験した本人であるという感覚(時間的な自己意識)を伴う点が、意味記憶との大きな違いとされています。

02身近な例

「去年の誕生日に友人からもらったプレゼント」のように、いつ・どこで・何があったかをセットで思い出せる記憶は、エピソード記憶の例です。

FAQよくある質問

エピソード記憶とは何ですか？

エピソード記憶とは、特定の時と場所で起きた個人的な出来事を、そのときの文脈とともに覚えている記憶のことです。

エピソード記憶と意味記憶の違いは何ですか？

エピソード記憶は、特定の時と場所で起きた個人的な出来事を、その文脈とともに覚えている記憶です。意味記憶は、世界についての一般的な知識や事実を覚えている記憶で、特定の出来事の文脈を伴いません。

エピソード記憶は海馬がないと持てないのですか？

海馬を含む脳の部位が損傷を受けた患者の研究では、エピソード記憶が深刻に損なわれる一方、意味記憶の多くは保たれることが報告されており、海馬がエピソード記憶の想起に重要な役割を果たすと考えられています。
