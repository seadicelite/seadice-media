ゼロから学ぶ行動経済学入門

全14章 ・ 公開中 58レッスン ・ 更新日 2026-10-06

ゼロから学ぶ行動経済学入門は、行動経済学の基礎をゼロから学べる無料のオンライン講座です。「人はいつも合理的に判断する」という前提のどこが現実とずれるのかを、日常の買い物やお金の例で順番に学べます。登録は不要で、1レッスン約5分で読めます。

第1章から学びはじめる用語辞典を見る

この講座の特徴

  • 1レッスンは約5分です。「このレッスンの問い → 前回の復習 → 本文と図 → あなたの場合は？ → 覚えるのはこの3つ → 確認問題」の順に進みます。読んだ直後に確認問題で思い出し、章の最後の章末テストで仕上げます。
  • 本文は、ノーベル賞の公式解説、環境省などの公的機関、OECD、原典の論文などの一次情報をもとに書いています。各レッスンの末尾に出典があります。
  • 追試で結果が揺らいでいる研究は、断定せずにその旨を書いています。
  • 確認問題はすべてオリジナルです。この講座は知識を学ぶための教材で、投資や家計についての個別の助言ではありません。
  • 読み終えたレッスン、章末テストのベストスコア、連続で学んだ日数、間違えた問題は、このブラウザだけに自動で記録されます（登録不要・外部には送りません）。記録は「わたしの学習」でまとめて見られ、ファイルに書き出して別の端末に移せます。間違えた問題は「復習」で解き直せ、用語は「暗記カード」で覚えられます。
